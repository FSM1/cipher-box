> cipherbox vault recovery

This tool recovers your CipherBox vault using your private key. It connects to IPFS gateways to retrieve your encrypted vault data. Your private key never leaves your browser.

Trust-nothing recovery: this page bundles all cryptography inline and speaks only to the IPFS/IPNS gateways you configure below. It never contacts the CipherBox API and never loads code from a public CDN.
