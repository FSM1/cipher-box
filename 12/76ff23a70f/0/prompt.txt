### Key Findings

- **FK map (D-01):** `folder_ipns` has zero SQL FK dependents from other tables. `shares.ipns_name`, `vaults.root_ipns_name`, and `ipns_republish_schedule.ipns_name` are all plain `varchar(255)` columns — not FK constraints. The migration drop-recreate order is straightforward: `DROP TABLE share_keys CASCADE` → `DROP TABLE shares CASCADE` → `CREATE TABLE shares` (new schema) → `DROP TABLE folder_ipns CASCADE` → `CREATE TABLE ipns_records`.

- **Current publish path is non-atomic (confirmed TOCTOU):** `upsertFolderIpns` (L214–L406 of `ipns.service.ts`) is a `findOne → gate → save` sequence. Two concurrent writers both at `dbSeq = N` both pass the in-memory CAS check, and the second `save` silently overwrites the first. The atomic replacement must use `createQueryBuilder().update().where('ipns_name = :n AND sequence_number = :expected AND generation &lt;= :incoming AND tombstoned_at IS NULL').execute()` and check `result.affected === 0`.

- **`parseCachedRecord` case-split (Test 15):** Current code at L64 returns `null` for both expected-null `signedRecord` (shared-folder rows) and CID-mismatch corruption, treating both as undifferentiated "fail closed." §6.5 requires differentiating: null `signedRecord` shared-folder rows should apply a `seq ≥ storedSeq` floor against the network record, not unconditionally 404.

- **NestJS 410 wiring:** `HttpStatus.GONE = 410` confirmed in installed NestJS ^11.0.0. `throw new HttpException({ error: 'IPNS_TOMBSTONED', ipnsName }, HttpStatus.GONE)` emits a typed JSON body that Swagger picks up and `pnpm api:generate` propagates into `@cipherbox/api-client`.

- **SDK-E2E concurrent-CAS forcing mechanism:** Phase 64/65 used a `persistCallback` hook injection (`rotation-crash-safety.test.ts` ~L628) to interpose a concurrent publish between rotation steps. Tests 16/17 use `Promise.allSettled` with two simultaneous `publishWithCas` calls at the same `expectedSequenceNumber`, then assert exactly one 409 and one 200 (test 16), and that `latestCid` is never regressed by a stale renewal (test 17).

Unique constraint changes from partial (`WHERE revoked_at IS NULL`) on `(sharer_id, recipient_id, ipns_name)` to plain `UNIQUE (sharer_id, recipient_id, root_node_id)`.
