| Boundary | Description |
|----------|-------------|
| crash mid-walk → fresh resume | a non-idempotent resume corrupts generations or skips nodes |
| concurrent client add ↔ in-flight rotation publish | a dropped concurrent add is silent data loss |
| test fault hook ↔ production engine | a production fault path would be a backdoor |
