<objective>
Extract the duplicated journal-dir + max-retries construction (#12) into one shared helper so the FUSE mount path and the sync daemon cannot silently drift. Behavior is byte-for-byte identical: same `<data_local_dir>/cipherbox/cb-journal` path, same temp_dir fallback, same `max_retries = 5`.

Purpose: Today `apps/desktop/src-tauri/src/fuse/mod.rs:103-117` and `apps/desktop/src-tauri/src/commands/sync.rs:57-63` each inline the same path chain and the literal `5`. A drift between them would split journal state across two directories — a silent durability bug. One helper removes that class of error.
Output: `pub fn default_journal_dir() -> PathBuf` + `pub const JOURNAL_MAX_RETRIES: u32 = 5` in `apps/desktop/src-tauri/src/fuse/mod.rs`, both call sites updated, plus a unit test pinning the path tail.
</objective>
