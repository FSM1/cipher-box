  <behavior>
    createFileMetadata: given a pre-uploaded cid + raw fileKey + iv + size/mimeType/encryptionMode, mints fileReadKey/fileWriteKey/Ed25519 keypair, builds NodeContent { cid, fileIv(base64), size, mimeType, encryptionMode, fileKey(raw), versions:[] }, builds a file Node (kind:'file', generation:0, writeBody:{ ipnsPrivateKey, writeChildren:[] }), sealNode(fileReadKey, fileWriteKey), publishes at seq 1n.     resolveFileMetadata: given a file IPNS name + the file's readKey, resolves + fetches the PublishedNode and returns unsealed NodeContent + metadataCid.
    updateFileMetadata: given the file's readKey/writeKey/ipnsPrivateKey + current NodeContent + new content, rebuilds the node preserving id/generation/createdAt, applies mergeVersions(existing, [prior current], MAX_VERSIONS_PER_FILE) when createVersion, republishes seq+1, returns { ipnsName, metadataCid, newSequenceNumber, prunedCids }.
    Cases: round-trip create→resolve returns identical cid/size/mimeType/iv; update with createVersion pushes prior into versions and caps at MAX_VERSIONS_PER_FILE returning the overflow prunedCids; first publish embeds 1n.
  </behavior>

Add a raw-fileKey content download helper (fetch CID + AES-GCM/CTR decrypt with the raw fileKey, base64 iv) consumed by 68.1-04/09. Zeroization (D-09): mint keys as `let x: Uint8Array | null`, fill(0)+null on success AND in catch/finally; NEVER zero caller-supplied buffers (mirror shared-write didDeriveWriteKey discipline). ## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sdk-core → CipherBox API/IPFS | Untrusted relay for file Node publish/resolve + content pins |
| minted file keys → GC | fileKey/fileReadKey/fileWriteKey/ipnsPrivateKey must be zeroed on all paths |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-68.1-07-01 | Information Disclosure | minted fileKey/fileReadKey/fileWriteKey/ipnsPrivateKey | high | mitigate | Mint as nullable, fill(0)+null on success AND catch/finally; never zero caller-supplied buffers; never log keys (D-09) |
| T-68.1-07-02 | Tampering | relay serves wrong/stale file Node on resolve | high | mitigate | unsealNode AEAD-authenticates against the file readKey; wrong/tampered node fails closed |
| T-68.1-07-03 | Elevation of Privilege | first file publish with seq != 1 | low | mitigate | createFileMetadata embeds 1n (strict gate) |
| T-68.1-07-04 | Tampering | version history unbounded / prune leak | medium | mitigate | mergeVersions caps at MAX_VERSIONS_PER_FILE; prunedCids returned so caller unpins overflow content |
| T-68.1-07-05 | Tampering | supply-chain: no new packages | low | accept | Phase adds zero npm deps — no package legitimacy gate required |
</threat_model>
