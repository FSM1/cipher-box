## Sampling Rate

- **After every task commit:** run the targeted Vitest file for sdk-core/sdk changes; `tsc -b` for web-only wiring (rebuild sdk-core/sdk dist first).
- **After every plan wave:** run the web-e2e spec(s) that the wave unblocks (e.g. read wave → `full-workflow` login/browse; write wave → upload/versions/sharing specs).
- **Before phase verification:** the FULL `pnpm test:web-e2e` suite must be green (all specs).
- **Max feedback latency:** targeted vitest < 30s; full web-e2e is the slow gate (run per wave + at phase end).
