| DB shares row | The active grant's wrapped readKey is load-bearing residue (design §2.8) |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-66-I2 | Information Disclosure | stale ECIES material in revoked rows | medium | mitigate | D-11 hard-delete on revoke (66-04); the entity has no `revoked_at` to strand key material |
| T-66-I3 | Information Disclosure | server seeing plaintext item names | low | mitigate | `itemNameEncrypted` (bytea) only; plaintext `item_name`/`itemName` columns dropped |
| T-66-T5 | Tampering | duplicate/parallel grant rows for one (sharer,recipient,root) | low | mitigate | plain `UNIQUE(sharer_id,recipient_id,root_node_id)` (D-06) |
| T-66-SC | Tampering | npm installs | high | accept | No package installs this phase |
