<objective>
Define the unified `Node` data model and its JSON encode/decode codec (no AEAD yet) in `packages/core/src/node/`, replacing the legacy `FolderMetadata`/`FileMetadata`/`FilePointer`/`FolderEntry` shapes. This is the first half of the keystone codec (D-06): pure in-memory `Node` ↔ plaintext body bytes.

Purpose: Establish the canonical v2.0 metadata type (`Node`/`SealedChildRef`/`PublishedNode`/`NodeContent`/`VersionEntry`/write-body) and the IV-independent body-byte encoding that every later phase seals against. Per D-03 the wire format is JSON (`JSON.stringify` → `TextEncoder`), mirroring today's `encryptFolderMetadata`.

Output: `node/types.ts`, `node/encode.ts`, `node/decode.ts`, and the `node-codec.test.ts` round-trip/validation suite. These are NEW files only — `folder/` and `file/` stay present this plan (retired in Plan 05), so `packages/core` keeps compiling.

This plan implements ZERO phase-63–69 behavior (no navigation walk, no rotation, no sealing, no share fan-out). Sealing/unsealing is Plan 02.
