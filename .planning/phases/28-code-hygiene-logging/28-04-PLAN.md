### Task 3: Add ESLint no-console rule

<read_first>

- eslint.config.js (current ESLint flat config)
- apps/web/src/main.tsx (lines 8-31 — DEV-only console.error override that must be allowed)
  </read_first>

<action>
Add a `no-console` rule to `eslint.config.js` that warns on raw `console.*` usage in production web app code. This prevents regression after the migration.

Add a new config object targeting web app source files:

```javascript
{
  files: ['apps/web/src/**/*.{ts,tsx}'],
  rules: {
    'no-console': ['warn', { allow: ['time', 'timeEnd'] }],
  },
},
```

The rule is set to `warn` (not `error`) to avoid blocking CI while still making console usage visible. `console.time`/`console.timeEnd` are allowed since they have no logger equivalent for browser performance timing.

The `main.tsx` DEV-only block will trigger the warning, which is acceptable — it's 3 console calls in a DEV-only block. If needed, add an `// eslint-disable-next-line no-console` comment to those specific lines in `main.tsx`.

Add eslint-disable comments to the 3 console calls in `main.tsx` that are in the DEV-only error handler block (lines ~12, ~17, ~27):

```typescript
// eslint-disable-next-line no-console
console.error(...);
```

</action>
