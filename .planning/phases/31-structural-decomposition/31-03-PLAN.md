# Plan 31-03: Hook Split and Component Extraction

<objective>
Split the three largest web app files into focused modules. useSharedNavigation.ts (1206 lines) splits into navigation state + write operations. FileBrowser.tsx (965 lines) splits into a presentational component + useFileBrowserActions hook. SharedFileBrowser.tsx (943 lines) splits into the main component + useSharedBrowserActions hook + extracted sub-components. All consumers retain identical behavior.
</objective>

<must_haves>

- `useSharedNavigation.ts` is under 700 lines after extracting write operations into `useSharedWriteOps.ts`
- `useSharedWriteOps.ts` contains all write operation handlers (upload, createFolder, rename, delete, updateFile) and the write helpers (buildSharedWriteCtx, withRevocationGuard, resyncSharedFolder)
- `FileBrowser.tsx` is under 500 lines after extracting handlers into `useFileBrowserActions.ts`
- `SharedFileBrowser.tsx` is under 600 lines after extracting handlers and sub-components
- `SharedListRow` and `SharedFolderRow` sub-components are in their own files
- All E2E tests (sharing-workflow, writable-shares, full-workflow, recycle-bin) still pass
- No `any` casts introduced
</must_haves>
