<objective>
Close SC#1: add a server-side child-ownership gate to BOTH invite and direct-share issuance. Verify the caller registered the shared node in `ipns_records` (creator marker) before persisting; reject 403 otherwise. Raises server-side ownership from *nothing* to *"the authenticated user who registered this node"* (D-01, amended). rootNodeId stays client-asserted — document that residual half-pair gap (D-02).

Purpose: `createInvite` and `createShare` copy the client's `shareRootIpnsName`/`rootNodeId` verbatim with zero server verification — any authenticated user can mint a grant claiming any node. The gate is defense-in-depth atop the cryptographic encrypted-key boundary (a forged grant for content the caller lacks keys to is cryptographically inert).
Output: ownership check on both create paths (using the renamed field `shareRootIpnsName`), the IpnsRecord DI wiring both services now need, and unit coverage (reject + accept) for both.
</objective>
