<objective>
Add TEE file enrollment to the desktop FUSE mount so that newly created files have their IPNS private keys wrapped with the TEE public key on first publish, enabling automatic 3-hour IPNS republishing by the TEE.

Purpose: Files created via the desktop app currently publish IPNS records without TEE enrollment (`encrypted_ipns_private_key: None`), meaning the TEE cannot republish their IPNS names. This makes file-level IPNS records go stale after 48 hours unless the user is online. The folder creation flow already has TEE enrollment (write_ops.rs:499-506); this plan replicates that pattern for per-file publishes.

Output: Modified `publish_file_metadata` on both Unix and Windows platforms that wraps the file IPNS key with the TEE public key on first publish.
</objective>
