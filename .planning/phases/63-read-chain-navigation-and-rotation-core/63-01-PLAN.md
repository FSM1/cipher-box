<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| relay → client | The IPNS/IPFS relay serves PublishedNode envelopes; untrusted, may serve stale or substituted records |
| grant holder → read chain | The grant readDescriptorRef holder unwraps one key and walks the chain |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-63-01 | Spoofing | navigateReadChain hop unseal | high | mitigate | AAD generation source is the parent `SealedChildRef.generation` mirror (integrity-anchored via the signed CID chain), not the relay-served child envelope; a stale pre-rotation CID fails GCM auth (design §2.6) |
| T-63-02 | Tampering | unsealChildReadKey AAD | high | mitigate | `buildNodeAad` binds childId + kind + generation + role 0x02; a transplanted sealed child-readKey fails the auth tag; navigation surfaces the throw, never a silent wrong key |
| T-63-03 | Information Disclosure | readKey buffers during walk | medium | mitigate | Navigation is a pure reader: never zero the caller-supplied recipient private key or chained readKeys (terminal-owner-only, D-09); never log key material |
| T-63-04 | Denial of Service | behind-retry vs revoked ambiguity | low | accept | Typed union forces the caller to branch explicitly; a malicious relay withholding a record maps to `revoked` (fail-closed), liveness recovered by caller retry on `behind-retry` |
</threat_model>
