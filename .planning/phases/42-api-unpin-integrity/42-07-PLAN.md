<objective>
Implement the D-09 one-shot historical backfill: a standalone maintenance script that repairs quota inflation accumulated while `recordUnpin` had zero callers. It diffs every NON-BYO user's `pinned_cids` rows against the live Kubo `pin ls` set and deletes rows whose CID is no longer physically pinned (the row was a phantom inflating `SUM(size_bytes)`). BYO users are excluded entirely — their advisory rows reference CIDs that were never on CipherBox's Kubo, so a "not on Kubo" signal is meaningless for them and deleting their rows would corrupt their advisory quota. A `--dry-run` flag reports the candidate deletions without mutating.

Purpose: The guarded-unpin path (42-03/05) stops NEW quota leaks, but existing users already carry inflated usage from historical deletes that never decremented. This script is the historical repair. It is deliberately a standalone script (not an app endpoint) so it runs ad-hoc via the same DataSource bootstrap as `run-migrations.ts`.
Output: `scripts/backfill-pinned-cids.ts` (DataSource bootstrap + non-BYO diff + batched delete + --dry-run), pure helpers in `apps/api/src/scripts/backfill-helpers.ts`, and a unit spec for the selection logic.
</objective>

## Trust Boundaries

| Boundary | Description |
| -------- | ----------- |
| operator to backfill script | a human runs the script ad-hoc; it holds DB delete authority over pinned_cids rows |
| script to Kubo pin/ls | read-only enumeration that decides which rows are phantoms; correctness depends on a reachable, populated Kubo |
| script to Postgres | DELETE on pinned_cids rows for non-BYO users only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --------- | -------- | --------- | ----------- | --------------- |
| T-42-22 | Tampering | backfill deleting legitimate BYO advisory rows | mitigate | The candidate query filters `vaults.is_byo_user = false` AND `selectRowsToDelete` re-asserts `isByoUser === false`; BYO rows are excluded at two layers (D-09). |
| T-42-23 | Denial of Service | empty/unreachable Kubo read as "all rows phantom" wiping every non-BYO row | mitigate | Mandatory guard: a failed `pin ls` fetch or empty parsed set aborts with non-zero exit and zero deletes before any DELETE runs. |
| T-42-24 | Tampering | accidental destructive default run | mitigate | A loud MODE banner prints at start; `--dry-run` reports without mutating so an operator can preview; deletes are id-scoped (`WHERE id = ANY`), never a blanket `DELETE FROM pinned_cids`. |
| T-42-25 | Information Disclosure | DB credentials leaked in error output | mitigate | Reuses run-migrations.ts secret-redacting error handler (`host\|password\|user(name)=` masked) so connection errors do not print secrets. |
| T-42-SC | Tampering | npm installs | accept | No new packages; typeorm + dotenv already in apps/api (RESEARCH audit). |
