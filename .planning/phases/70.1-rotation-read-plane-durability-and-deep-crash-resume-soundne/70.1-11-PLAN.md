<objective>
Fix three of the four bundled gate-correctness bugs in `grant_scope.rs` (D-15a CRITICAL cache fail-open, D-15b MAJOR ancestor-walk fail-open, D-15c MAJOR poisoned-lock panic). These are latent today (a wrong "NoRotation" just skips a rotation that would EIO anyway) but become LIVE revocation-bypass vectors now that Plan 09 wired real rotation.

Grounding (RESEARCH Sharp Question 7.3 a/b/c + Pitfall 8, confirmed live):
- **D-15a:** `SentSharesCache` (`grant_scope.rs:99-124`) is `#[derive(Default)]` with `empty()`. `run_scope_exit_gate` reads `fs.sent_shares.read()...clone()` (`:310-314`); on an empty set `grant_root_for` returns `None` → `NoRotation` → a shared delete looks private and skips rotation. The window: before the first `refresh_sent_shares` completes (or if it FAILED), EVERY delete/move — including a genuinely-shared one — silently bypasses rotation. Fix: add an authoritativeness flag (`is_authoritative`, false for `empty()`/`Default`, true only after a successful `from_sent_shares` refresh); the gate returns `Err`(→EIO) when NOT authoritative — WITHOUT breaking a legitimately-empty authoritative cache. Pitfall 8: the trigger is "has a successful /shares/sent refresh completed," NOT "is the set empty."
- **D-15b:** `ancestor_ipns_chain` (`:51-88`) `break`s on a missing inode (`:64-66`) and a cycle (`:60-62`), returning a PARTIAL `Vec<String>` that may omit the true grant-root — so a covered node with a broken path looks private. `:81-83` is the only clean terminator (reached ROOT_INO). Fix: distinguish "reached ROOT_INO cleanly" from "broke early"; return a result the gate treats as fail-closed (Err→EIO) when the walk did NOT terminate at ROOT_INO (change the `Vec<String>` return to a Result/Option or add a companion `reached_root: bool`).
- **D-15c:** `run_scope_exit_gate` does `fs.sent_shares.read().expect("sent_shares lock poisoned")` (`:310-314`) — a poisoned RwLock panics the fuser callback thread and can wedge the mount. `fs.rs:103` uses the same `.expect(...)`. Fix: handle the poison as `Err(())`→EIO (fail-closed, no panic), consistent with the surrounding `Result<(), ()>` flow.

Purpose: close the three live revocation-bypass / mount-wedge vectors the moment rotation is wired.
Output: authoritativeness flag + fail-closed ancestor + poisoned-lock handling, gated by new grant_scope unit tests. Implements D-15a/b/c.
</objective>
