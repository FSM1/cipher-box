Fix the fourth bundled gate-correctness bug (D-15d gate ordering in delete.rs/rename.rs) and invert the test that asserted fail-closed-until-wired now that Plan 09 wired rotation.

Grounding (RESEARCH Sharp Question 7.3 (d) + 7.5 blast radius, confirmed live):
- **delete.rs bin-ref build-before-gate:** `bin_entry_data` (the D-07 dual `SealedChildRef`/`WriteChildRef`, sealed under the parent's CURRENT keys) is built at the TOP of `handle_unlink` (`:94-190`) and `handle_rmdir` (`:300-387`) BEFORE `run_scope_exit_gate` fires (`:200`/`:399`). If the gate rotates the grant-root ancestor (re-sealing the parent's SealedChildRef list under a new key), the bin entry captured a stale-key ref. Fix: move the `build_child_refs` capture to AFTER `run_scope_exit_gate` succeeds (or re-derive post-gate).
- **rename.rs dest_ino gating gap:** `handle_rename` runs the gate on the SOURCE ancestry only (`:101-106`) BEFORE the destination-replacement block (`:115-166`). Two problems: (i) POSIX replacement validation (ENOTDIR `:134`, EISDIR `:138`, ENOTEMPTY `:146`) runs AFTER the gate, so a shared-scope-exit move that will fail POSIX still rotates; (ii) the destination node being REPLACED (`:164-165`) is a potentially-shared node whose OWN scope-exit is never gated. Fix: run POSIX replacement checks BEFORE the gate, and add a scope-exit gate for the REPLACED dest_ino when it is being removed. Mirror delete.rs's "validation before gate before mutation."
- **Test inversion:** `unlink_shared_scope_exit_fails_closed_until_rotation_wired` (`delete.rs:645`) currently ASSERTS EIO; post-wiring it must assert success + rotation (it INVERTS). The two private-delete tests (`unlink_private_delete_succeeds_with_zero_rotation :596`, `rmdir_private_delete_succeeds_with_zero_rotation :619`) must seed an AUTHORITATIVE-but-empty cache (Pitfall 8) so they keep asserting the private-delete-succeeds path.

Purpose: close the last live gate-ordering vector (spurious rotation on a rejected move, ungated replaced dest, stale-key bin ref) and reconcile the test suite with the now-live rotation.
Output: gate ordering fixes + dest_ino gating + inverted/updated tests. Implements D-15d and the D-14 inversion.
