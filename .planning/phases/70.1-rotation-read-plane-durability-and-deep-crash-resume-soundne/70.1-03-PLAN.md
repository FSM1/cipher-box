<objective>
Make the Rust (`crates/sdk`) durable floor plane atomic and fail-closed (SC#4/D-06/D-08) and fold the SC#3 wrapped-key checkpoint into the same per-nodeId record (D-07 Rust half).

Grounding (RESEARCH Sharp Question 3 + 6.4, confirmed live):
- `JsonSidecarFloorStore` ALREADY has `write_map_atomic_blocking` (temp+rename, `:101-125`), a whole-critical-section `tokio::sync::Mutex`, and corrupt-sidecar fail-closed (`CORRUPT_SIDECAR_FAIL_CLOSED_FLOOR = i64::MAX`, shipped Phase 70). The gaps are: (1) TWO separate sidecar files via `for_generation`/`for_seq` (`:158-166`) — collapse to ONE `HashMap<String, CombinedFloorRecord>`; (2) `HighWaterStore::put` (`high_water.rs:32-37`) returns `()` and the impl only `log::error!`s I/O failures (`floor_store.rs:226-238`) — the literal D-08 bug; make it `Result`.
- Changing `put -> Result` ripples through `bump_floor` (`high_water.rs:114-127`, `-> u64`) and `enforce_resolved` (`:287-288`). Blast radius (RESEARCH Assumption A3, grep-confirmed): `crates/fuse/src/{content_ops,inode,events,fs,replay}.rs` and `crates/sdk/src/{adapter,lib,listing,emit}.rs`.

Purpose: the shared durable plane both Rust engines (Plan 08) and the FUSE adapter (Plan 09) depend on; a swallowed floor write is a silent durability defect.
Output: `CombinedFloorRecord`, fail-closed `put`, single combined sidecar, consumer sweep. Implements D-06, D-07, D-08.
</objective>
