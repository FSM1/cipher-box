## Shared Patterns

### Callback-seam no-op contract (D-04)
**Source:** `packages/sdk-core/src/rotation/engine.ts:441-452` (`reMintGrantsRootedAt`) / `crates/sdk/src/rotation/engine.rs:180-199` (`RotationDeps` default methods)
**Apply to:** the new `keyCheckpointCallbacks` (TS) / `persist_wrapped_key`/`get_wrapped_key`/`delete_wrapped_key` (Rust) seams in BOTH engines.
```typescript
if (!callbacks) return; // clean happy-path never invokes this seam
```
```rust
async fn persist_wrapped_key(&self, _node_id: &str, _wrapped_b64: &str) -> Result<(), RotationError> { Ok(()) }
```

### Terminal-owner zeroization
**Source:** `engine.ts:1650-1656` (`finally { item.nodeReadKey.fill(0); }`), `:1292` (`parentOldReadKey.fill(0)`)
**Apply to:** the new recovered `readKeyPrime` (TS `unwrapKey` result) / recovered key (Rust `unwrap_key` `Zeroizing<Vec<u8>>`) — zero exactly once, at `ParentTrackingState` teardown, never inside the unwrap function itself. This is the exact class that broke 48/89 sdk-e2e previously (project memory) — treat every new `fill(0)`/drop site with a comment identifying the terminal owner.

### Fallback typed-error + catch-site pattern
**Source:** `RootKeyStaleError` (`engine.ts:302-307`, thrown `:1004-1018`, caught `client.ts:2016-2069`)
**Apply to:** new `DirtyNodeUnrecoverableError` (D-05 fallback for truly-expired/GC'd-key case) — same class+catch shape, different (narrower) fallback action.

### Atomic single-record collapse
**Source:** Rust `write_map_atomic_blocking` (`floor_store.rs:101-125`), TS `idbPut` (`rotation-state.service.ts:90-111`)
**Apply to:** `CombinedFloorRecord` (Rust) / single IndexedDB object store (TS) merging generation+seq+wrappedKeyCheckpoint (D-06/D-07). Do not invent new atomicity machinery — the existing primitives already provide it once there is only one record to write.

### Fail-closed Result propagation
**Source:** `RotationError` (Rust, already the fail-closed contract used elsewhere in `high_water.rs`)
**Apply to:** `HighWaterStore::put` signature change (D-08) — propagate through `bump_floor`, `enforce_resolved`, and the wrapped-key persist call (a lost checkpoint write must also fail closed, per D-04/D-07 shared-plane reasoning).
