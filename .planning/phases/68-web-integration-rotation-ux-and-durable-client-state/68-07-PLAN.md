Wire the Q3 owner-reconcile authority mirror on web (D-10/D-11 — mirrors Phase 65 D-01). When a write-recipient C independently unlinks+bins a node the owner sub-shared to D, the owner's reconcile pass re-derives the dangling grants by driving `reMintGrantsRootedAt` (sdk-core, built + mock-tested in Phase 65) with **real** API-backed `GrantRemintCallbacks`:

- `queryGrantsFn(nodeId)` → `sharesControllerGetSentShares` filtered client-side by `rootNodeId` (RESEARCH.md A3 — acceptable v1; no indexed endpoint).

Purpose: Minimize the dangling-grant window with no new schema; live-wire the Phase-65 mock-tested reconcile seam.
Output: An owner-reconcile web service + its callbacks + the eager login trigger.

Covers: D-10, D-11.
</objective>
