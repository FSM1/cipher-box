<objective>
Close the four sdk-core/web spillover correctness bugs from the PR #538 second CodeRabbit pass: `fetchAndDecryptMetadata` must wrap its decode/parse/decrypt in a try-catch and throw a typed error (D-13); `registration.ts` must move both `wrapKey` calls inside the try whose catch zeroes key material so a throw still clears the buffers (D-13); `DetailsPrimitives` must gate `setCopied(true)` on an actual successful copy (D-14); `VersionHistory` must surface a user-visible error instead of silently returning when the vault private key is missing (D-14).

Purpose: V6 Cryptography — a `wrapKey` throw before the zeroizing catch leaks IPNS/folder key material on the heap (Information Disclosure). The other three are "no swallowed decision" UX/error-surfacing fixes: an opaque decode throw, a false "Copied!" state, and a silent download no-op.

Output: A typed-failure metadata decode path, a leak-safe registration zeroization window, copy-success-gated UI, and a surfaced version-download error — with Vitest unit tests (`.test.ts`, NOT `.spec.ts`, since web/sdk-core vitest `include` is `src/**/*.test.ts`).
</objective>

| Clipboard / DOM API → UI state | `navigator.clipboard` / `execCommand` may fail silently; UI must reflect actual outcome. |
