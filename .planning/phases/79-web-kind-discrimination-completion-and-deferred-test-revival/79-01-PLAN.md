<objective>
Extend the SDK read-listing projection so every ResolvedChild carries a real `createdAt`,
sourced from the already-unsealed `Node.createdAt`. This is the load-bearing foundation for SC2
(details panes show a real Created date) and it is the only NEW SDK field this phase introduces.

Because `createdAt` is a MANDATORY field (mirroring `modifiedAt`, not optional like `size`),
adding it forces every `ResolvedChild` object literal in `packages/sdk` to gain the field or the
package stops typechecking. This plan owns the entire `packages/sdk` blast radius so the CI-gated
`Test` job stays green as a unit.

Purpose: SC2 requires a Created date sourced from the Node envelope, not the "unavailable
(phase 63)" stub. `Node.createdAt` already exists (packages/core/src/node/types.ts:166) and is
already decrypted inside resolveChildren() for `kind`/`modifiedAt` — this surfaces it with zero
new codec/seal work.
Output: `ResolvedChild.createdAt: number` + every in-package literal updated + a resolveChildren
createdAt assertion.
</objective>
