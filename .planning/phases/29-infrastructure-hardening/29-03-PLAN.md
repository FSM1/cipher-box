<action>
Create `docker/grafana/alerts/test-login-rate.json` with a single alert rule:

```json
[
  {
    "title": "Test Login Rate High",
    "ruleGroup": "CipherBox Security",
    "folderUID": "GRAFANA_ALERTS_FOLDER_UID",
    "noDataState": "OK",
    "execErrState": "OK",
    "for": "5m",
    "condition": "B",
    "annotations": {
      "summary": "Test login rate exceeds 100/hour on staging",
      "description": "The POST /auth/test-login endpoint is being called more than 100 times per hour. This may indicate unauthorized access attempts or misconfigured test automation. Verify the TEST_LOGIN_SECRET is not leaked and check request source IPs."
    },
    "labels": {
      "severity": "warning",
      "service": "cipherbox",
      "operation": "test-login"
    },
    "data": [
      {
        "refId": "A",
        "queryType": "",
        "relativeTimeRange": { "from": 3600, "to": 0 },
        "datasourceUid": "GRAFANA_CLOUD_DATASOURCE_UID",
        "model": {
          "expr": "increase(cipherbox_auth_logins_total{method=\"test\"}[1h])",
          "intervalMs": 60000,
          "maxDataPoints": 43200,
          "refId": "A"
        }
      },
      {
        "refId": "B",
        "queryType": "",
        "relativeTimeRange": { "from": 3600, "to": 0 },
        "datasourceUid": "__expr__",
        "model": {
          "type": "threshold",
          "expression": "A",
          "conditions": [
            {
              "evaluator": { "type": "gt", "params": [100] },
              "operator": { "type": "and" },
              "query": { "params": ["B"] },
              "reducer": { "type": "last", "params": [] }
            }
          ],
          "refId": "B"
        }
      }
    ]
  }
]
```

Key design decisions:

- Threshold of 100 per hour — normal E2E test runs do ~5-10 logins; 100 would indicate anomalous usage
- 5-minute `for` duration prevents false positives from legitimate batch test runs
- `noDataState: "OK"` — no alert when metric is absent (metric only emits when test login is used)
- Uses `increase()` over 1h window to count total calls, not instantaneous rate
- Severity "warning" (not critical) since test login is only available on staging
