<objective>

- **69-09 (P1)** — the FUSE read/write/replay/delete/rename path.

- **69-20 (P4b)** — vault-creation (`initialize_vault` emits an empty node/v3 Root; `vault.rs` no longer names `FolderMetadata`).

- `file.rs`: reduce the re-export to just `pub use crate::folder::VersionEntry;` (drop `FileMetadata`/`FilePointer`/`encrypt_file_metadata`/`decrypt_file_metadata`).

**Delete set (crates/fuse + desktop, default build):**
