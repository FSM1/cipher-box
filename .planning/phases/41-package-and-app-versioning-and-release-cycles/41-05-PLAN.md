**Part A: Update release-please.yml for desktop release handling**

The RP action (googleapis/release-please-action@v4) when run with `include-component-in-tag: true` for the desktop package will automatically create a `cipherbox-desktop-vX.Y` tag and a corresponding GitHub Release when the desktop version bumps.

However, we need to ensure the Tauri updater JSON asset gets published on desktop releases. Currently, the updater JSON is only published during staging deploys (via tauri-action in deploy-staging.yml).

For production releases, we need to add a job to the release-please workflow that:

1. Detects if desktop was released
2. Builds desktop binaries for the release
3. Publishes updater JSON as a release asset on the desktop-specific release

This is actually a significant build pipeline addition. For now, keep the current model where staging IS production (the deploy-staging workflow builds desktop and publishes updater JSON). The desktop-specific tag from RP serves as a version marker, and the Tauri updater continues to use the staging release for downloads.

So the release-please.yml change is minimal — add an output step that logs which components were released:

````yaml
name: Release Please

on:
  push:
    branches:
      - main

permissions:
  contents: write
  pull-requests: write

jobs:
  release-please:
    runs-on: ubuntu-latest
    outputs:
      releases_created: ${{ steps.release.outputs.releases_created }}
    steps:
      - uses: actions/create-github-app-token@v3
        id: app-token
        with:
          app-id: ${{ vars.RELEASE_BOT_APP_ID }}
          private-key: ${{ secrets.RELEASE_BOT_PRIVATE_KEY }}

      - uses: googleapis/release-please-action@v4
        id: release
        with:
          config-file: release-please-config.json
          manifest-file: .release-please-manifest.json
          token: ${{ steps.app-token.outputs.token }}

      - name: Release summary
        if: steps.release.outputs.releases_created == 'true'
        env:
          RELEASES_OUTPUT: ${{ toJSON(steps.release.outputs) }}
        run: |
          echo "## Releases Created" >> "$GITHUB_STEP_SUMMARY"
          echo '```json' >> "$GITHUB_STEP_SUMMARY"
          echo "$RELEASES_OUTPUT" | jq '{releases_created, paths_released}' >> "$GITHUB_STEP_SUMMARY"
          echo '```' >> "$GITHUB_STEP_SUMMARY"
````
