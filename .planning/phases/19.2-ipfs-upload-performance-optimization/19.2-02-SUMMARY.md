## Decisions Made

- **Combined profiles:** Used `server,pebbleds` (not just `pebbleds`) for staging to retain the server profile's network settings alongside the pebbleds datastore.
- **Volume recreation required:** Pebbleds cannot convert from flatfs in-place. Docker volume must be deleted before first start with new profile. Documented in compose file comments.
- **Local baselines only:** Post-optimization baselines captured against local infrastructure since staging has not been redeployed yet. Definitive comparison requires staging validation.
