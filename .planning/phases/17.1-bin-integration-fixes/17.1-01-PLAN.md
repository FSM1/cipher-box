<objective>
Fix GAP-1 (CRITICAL): Bin permanent delete cannot unpin file CIDs because unpinFileCids()
attempts to decrypt AES-256-GCM-encrypted file metadata as plain JSON. The fix stores plaintext
CID and size in BinEntry at soft-delete time (when the data is already available in memory),
then uses these stored fields at permanent-delete time instead of re-resolving encrypted IPNS metadata.

Purpose: Without this fix, permanently deleting bin items never reclaims IPFS storage or updates quota.
Output: BinEntry schema extended with optional contentCid/contentSize, web and desktop soft-delete paths
capture these fields, unpinFileCids uses stored fields.
</objective>

    **Web: Fix unpinFileCids** (`apps/web/src/services/bin.service.ts`):

    Rewrite `unpinFileCids` to accept the BinEntry directly and use stored contentCid/contentSize:
    ```typescript
    async function unpinFileCids(entry: BinEntry): Promise<void> {
      try {
        // Prefer stored CID/size from soft-delete time (GAP-1 fix)
        if (entry.contentCid) {
          await unpinFromIpfs(entry.contentCid);
          if (entry.contentSize && typeof entry.contentSize === 'number') {
            useQuotaStore.getState().removeUsage(entry.contentSize);
          }
          // Also unpin the metadata CID
          if (entry.filePointer) {
            const resolved = await resolveIpnsRecord(entry.filePointer.fileMetaIpnsName);
            if (resolved?.cid) {
              await unpinFromIpfs(resolved.cid).catch(() => {});
            }
          }
          return;
        }

        // Fallback for legacy entries without contentCid (will fail for encrypted metadata,
        // but keeps existing behavior for any entries that somehow have plain metadata)
        if (!entry.filePointer) return;
        const fileIpnsName = entry.filePointer.fileMetaIpnsName;
        if (!fileIpnsName) return;

        const resolved = await resolveIpnsRecord(fileIpnsName);
        if (!resolved?.cid) return;

        const metaBytes = await fetchFromIpfs(resolved.cid);
        const metaJson = new TextDecoder().decode(metaBytes);
        const fileMeta = JSON.parse(metaJson);

        if (fileMeta.cid) {
          await unpinFromIpfs(fileMeta.cid);
          if (fileMeta.size && typeof fileMeta.size === 'number') {
            useQuotaStore.getState().removeUsage(fileMeta.size);
          }
        }

        await unpinFromIpfs(resolved.cid).catch(() => {});
      } catch (err) {
        console.error(`[Bin] CID cleanup failed for file ${entry.id}:`, err);
      }
    }
    ```
