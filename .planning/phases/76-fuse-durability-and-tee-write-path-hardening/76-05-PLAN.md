<objective>
Mirror the already-shipped Unix D-07 write-plane keying fix (commit c4d30e598) into the Windows/WinFsp platform layer (SC2 item 3; closes the Windows part of todo:2026-07-07-fuse-publish-and-concurrency-hardening-deferred). Today the Windows `cleanup()` delete/bin-capture path derives the D-07 write child id from `uuid_from_ino(ino)`, which is correct only for freshly-minted local nodes; a materialized/replayed node must key by its persisted `InodeData.node_id` so the bin entry pairs correctly on restore.

This is a platform/glue fix that does NOT compile under local macOS cargo — it is verifiable only via the Windows CI jobs. The plan is therefore `autonomous: false` with a blocking checkpoint confirming CI is green before merge.

Purpose: cross-platform parity of the D-07 dual-keying correctness fix.
Output: `crates/fuse/src/platform/windows/write_ops.rs` node_id-keyed child_id + a ported D-07 regression test, gated on Windows CI.
</objective>
