- Test decryptIpnsKey(encrypted, 1) returns the original payload
- Test decryptIpnsKey(encrypted, 2) throws (wrong epoch)
- Test decryptWithFallback(encrypted, 1, null) succeeds with usedEpoch=1
- Test decryptWithFallback: encrypt with epoch 2 public key, call decryptWithFallback(encrypted, 1, 2) -- should fall back to epoch 2
- Test decryptWithFallback: encrypt with epoch 3 public key, call decryptWithFallback(encrypted, 1, 2) -- should throw "all available epochs"
- Test reEncryptForEpoch: decrypt key from epoch 1, reEncrypt for epoch 2, then decryptIpnsKey with epoch 2 should succeed

**ipns-signer.test.ts:**

- Import { unmarshalIPNSRecord } from 'ipns' and verify it can parse the result without throwing
- Call twice with same inputs, verify both produce non-empty output (not necessarily identical due to timestamps)

**auth.test.ts:**

- Create mock Express req/res/next objects
- Test missing TEE_WORKER_SECRET: call authMiddleware, expect res.status(500) with { error: 'TEE_WORKER_SECRET not configured' }

- Test timing-safe: set Authorization='Bearer x' (different length), expect res.status(401) -- verifies length check before timingSafeEqual
