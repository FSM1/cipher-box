<objective>
Add `renewIpnsRecord` to the TEE signer: the pure lease-renew transform at the heart of the new contract (D-01 / TEE-01 / TEE-02 / §6.4). It parses the marshaled existing record and re-signs the SAME value (CID) and SAME `sequenceNumber` with only a later EOL — it cannot originate or repoint a CID, and it cannot increment the sequence. The existing `signIpnsRecord` (create-from-scalars) is kept unchanged for back-compat.

Purpose: Isolate the "re-sign the verified record's own value/sequence" primitive so the route (67-06) composes verify-in-enclave → renew without ever passing a relay-supplied CID or incremented sequence.
Output: `renewIpnsRecord(ed25519PrivateKey, marshaledExistingRecord, lifetimeMs)` + red→green unit tests proving equal-CID / equal-seq / later-EOL.
</objective>
