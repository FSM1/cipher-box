# Plan 30-01: Grafana Faro SDK Initialization with Privacy Scrubbing

<objective>
Install Grafana Faro packages, create the Faro initialization module with strict privacy scrubbing (beforeSend hook), and call initialization from main.tsx. When VITE_FARO_URL is absent (local dev), Faro is completely disabled. When present (staging/production), all error payloads are scrubbed of sensitive fields before leaving the browser.
</objective>

## Background

CipherBox is a zero-knowledge encrypted storage app. Error tracking must never leak encryption keys, access tokens, or user-identifying information to third-party services. Grafana Faro was chosen over Sentry because it keeps all observability within the existing Grafana Cloud stack, has no session replay (privacy advantage), and provides built-in web vitals collection.

The `beforeSend` hook is the critical privacy gate — it strips all sensitive fields from every payload before it leaves the browser.

## must_haves

- `@grafana/faro-web-sdk` and `@grafana/faro-react` installed as dependencies
- Faro initialization module at `apps/web/src/lib/faro.ts`
- `beforeSend` hook strips: `privateKey`, `rootFolderKey`, `folderKey`, `fileKey`, `accessToken`, `ipnsPrivateKey`, `teePublicKey`, `userEmail`
- `beforeSend` strips any string value that looks like a hex-encoded key (64+ hex chars = 32+ bytes)
- `beforeSend` strips any Uint8Array-like values from payloads
- Network request/response body capture disabled
- DOM text in breadcrumbs disabled
- User identity set to `publicKey` hex only (never email)
- Faro completely disabled when `VITE_FARO_URL` is absent
- `initFaro()` called from `main.tsx` before the React render tree

### Task 2: Create Faro initialization module with privacy scrubbing

<read_first>

- apps/web/src/lib/logger.ts (to see the Transport type and transports array from Phase 28 — the Faro transport will be registered here in a later plan)
- apps/web/src/main.tsx (to see the bootstrap sequence and where initFaro will be called)

- apps/web/src/stores/folder.store.ts (to see folderKey, ipnsPrivateKey as Uint8Array)
  </read_first>

<action>
Create `apps/web/src/lib/faro.ts` with the following implementation:

1.  Import from `@grafana/faro-web-sdk`:
    - `initializeFaro`, `getWebInstrumentations`, `type Faro`, `type TransportItem`

2.  Import from `@grafana/faro-react`:
    - `ReactIntegration`

3.  Define `SENSITIVE_KEYS` constant (matching Phase 28 logger's set, plus Faro-specific additions):

    ```typescript
    const SENSITIVE_KEYS = new Set([
      'privateKey',
      'rootFolderKey',
      'folderKey',
      'fileKey',
      'accessToken',
      'ipnsPrivateKey',
      'teePublicKey',
      'userEmail',
    ]);
    ```

4.  Define `HEX_KEY_PATTERN` regex to detect hex-encoded keys (64+ hex chars = 32+ bytes):

    ```typescript
    const HEX_KEY_PATTERN = /^[0-9a-fA-F]{64,}$/;
    ```

5.  Implement `scrubValue(value: unknown): unknown` helper:
    - If value is a string matching `HEX_KEY_PATTERN`, return `'[REDACTED_KEY]'`
    - If value is an object with `buffer` property and `byteLength` property (Uint8Array-like), return `'[REDACTED_BINARY]'`
    - If value is an ArrayBuffer or typed array (check via ArrayBuffer.isView), return `'[REDACTED_BINARY]'`
    - Otherwise return value unchanged

6.  Implement `scrubObject(obj: Record<string, unknown>): Record<string, unknown>`:
    - Shallow-clone the object
    - For each key: if key is in `SENSITIVE_KEYS`, set value to `'[REDACTED]'`
    - For each remaining key: run `scrubValue()` on the value
    - For nested objects (typeof value === 'object' && value !== null && !Array.isArray(value)), recurse one level deep
    - Return the scrubbed clone

7.  Implement `beforeSend(item: TransportItem): TransportItem | null` hook:
    - If `item.payload` exists and is an object, deep-scrub it via `scrubObject`
    - If item contains exception frames with local variables, scrub those
    - Strip any `meta.user.email` if present — only allow `meta.user.id` (publicKey)
    - Return the scrubbed item

8.  Export `initFaro()` function:

    ```typescript
    export function initFaro(): Faro | undefined {
      const faroUrl = import.meta.env.VITE_FARO_URL;
      if (!faroUrl) return undefined;

      return initializeFaro({
        url: faroUrl,
        app: {
          name: 'cipherbox-web',
          version: import.meta.env.VITE_APP_VERSION ?? 'dev',
          environment: import.meta.env.VITE_ENVIRONMENT ?? 'development',
        },
        instrumentations: [
          ...getWebInstrumentations({
            captureConsole: false, // Phase 28 logger handles console capture
            captureConsoleDisabledLevels: [],
          }),
          new ReactIntegration(),
        ],
        beforeSend,
        // Privacy: disable network body capture
        // Privacy: disable DOM text in breadcrumbs
        sessionTracking: {
          enabled: true,
          persistent: false, // Don't persist session across tabs
        },
      });
    }
    ```

    Note: The exact configuration options for disabling network body capture and DOM text will depend on the Faro SDK version. Check the SDK's `getWebInstrumentations()` options and `FetchTransport`/`XHRTransport` configuration. Key options to look for:
    - `captureConsole: false` (we use our own logger)
    - Fetch/XHR instrumentation: disable request/response body capture
    - DOM instrumentation: disable text content capture in click breadcrumbs

9.  Export `setFaroUser(publicKey: string)` function:

    ```typescript
    export function setFaroUser(publicKey: string): void {
      const faro = getFaroInstance();
      if (!faro) return;
      faro.api.setUser({ id: publicKey });
    }
    ```

    Where `getFaroInstance()` returns the stored Faro instance (or undefined if not initialized).

10. Export `faro` instance reference for use by error boundary and logger transport:
    ```typescript
    let faroInstance: Faro | undefined;

        export function getFaroInstance(): Faro | undefined {
          return faroInstance;
        }
        ```

        Update `initFaro()` to store: `faroInstance = initializeFaro({...}); return faroInstance;`

    </action>
