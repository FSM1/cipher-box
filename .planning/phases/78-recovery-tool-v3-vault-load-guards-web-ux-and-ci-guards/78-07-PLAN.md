<objective>
Fix the SC3c/D-08 item-3 poll-monotonicity data-integrity race: a slow in-flight poll response applied by `useSyncPolling.ts::invalidateOpenFolder` can clobber a newer nav-triggered folder state. Add a deterministic web-e2e regression spec that reproduces the race without relying on poll timing.

Purpose: Eliminate a silent folder-state corruption where a stale poll overwrites fresher navigation state.
Output: A sequence-guarded `invalidateOpenFolder`; a new permanent `poll-monotonicity.spec.ts`.
</objective>
