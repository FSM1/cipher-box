<objective>
Add a CID registration endpoint for BYO users to report externally-pinned CIDs, and make quota tracking advisory (non-enforced) for BYO users. This enables the "lightweight API footprint" pattern where BYO users pin directly to their own node and only notify CipherBox of CID + size for informational tracking.

Purpose: BYO users bypass the CipherBox upload relay. The API needs a way to track their CIDs for advisory quota display without enforcing limits, since storage is managed by the user's own node.

Output: New `/ipfs/register-cid` endpoint, advisory quota mode in VaultService, `isByoUser` flag on vault entity.
</objective>

  summary: 'Register externally-pinned CID for advisory quota tracking',

  description: 'CID registered for tracking',

  const isByo = await this.isUserByo(userId);
  if (isByo) return true; // Advisory only -- always allow

Modify `getQuota` to include advisory flag:

```typescript
async getQuota(userId: string): Promise<QuotaResponseDto> {
  const isByo = await this.isUserByo(userId);

  const result = await this.pinnedCidRepository
    .createQueryBuilder('pin')
    .select('COALESCE(SUM(pin.size_bytes), 0)', 'total')
    .where('pin.user_id = :userId', { userId })
    .getRawOne<{ total: string }>();

  const usedBytes = parseInt(result?.total ?? '0', 10);
  const remainingBytes = Math.max(0, QUOTA_LIMIT_BYTES - usedBytes);

  return {
    usedBytes,
    limitBytes: QUOTA_LIMIT_BYTES,
    remainingBytes,
    advisory: isByo,
  };
}
```
