<objective>
Add TEE-routed connection test endpoint to avoid browser CORS and credential exposure issues

Purpose: The current connection test runs in the browser, which means: (a) CORS blocks many SaaS providers that don't set Access-Control-Allow-Origin, (b) auth tokens are used directly in browser fetch requests. By routing through the TEE, credentials are ECIES-encrypted before leaving the browser, decrypted only in the TEE enclave, and the TEE probes the endpoint server-side where CORS doesn't apply.

Output: POST /tee/connection-test API endpoint, TEE worker /connection-test route, updated ConnectionTest component using server-side testing.
</objective>

    **2. Add endpoint to `apps/api/src/tee/tee.controller.ts`:**

    Add a new POST method `connectionTest`:

    ```typescript
    @Post('connection-test')
    @Throttle({ default: { limit: 10, ttl: 60000 } }) // 10 per minute per user
    @ApiOperation({
      summary: 'Test connection to an external IPFS provider via TEE',
      description: 'Forwards ECIES-encrypted provider config to TEE worker for server-side connection testing. Avoids browser CORS issues and keeps credentials encrypted until decrypted in-enclave.',
    })
    @ApiResponse({ status: 200, type: ConnectionTestResponseDto })
    async connectionTest(
      @Body() dto: ConnectionTestRequestDto,
    ): Promise<ConnectionTestResponseDto> {
      // Forward to TEE worker
      const teeWorkerUrl = this.configService.get<string>('TEE_WORKER_URL');
      const teeWorkerSecret = this.configService.get<string>('TEE_WORKER_SECRET');

      const response = await fetch(`${teeWorkerUrl}/connection-test`, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          Authorization: `Bearer ${teeWorkerSecret}`,
        },
        body: JSON.stringify({
          encryptedConfig: dto.encryptedConfig,
          epoch: dto.epoch,
        }),
        signal: AbortSignal.timeout(30_000), // 30s total (includes 10s probe timeout)
      });

      if (!response.ok) {
        const errorText = await response.text();
        return {
          success: false,
          latencyMs: 0,
          error: `TEE worker error: ${response.status} - ${errorText}`,
        };
      }

      return (await response.json()) as ConnectionTestResponseDto;
    }
    ```
