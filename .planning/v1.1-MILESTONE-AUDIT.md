### Phase 39 deviations (detail)

1. **D-02 — no permanent-delete confirmation (data-safety UX gap).** When the user's default delete mode is hard/permanent, `useFolderMutations.ts:23-33` calls `client.deleteItem()` directly with no "data is unrecoverable" prompt. The soft/hard *setting* works; the per-action safety dialog CONTEXT D-02 specified is missing. **Recommend a follow-up todo.**
2. **D-06 — residual server env-var surface.** Client fully migrated to encrypted vault settings (zero `/vault/config` reads in `apps/web`), but the server still reads + exposes `RECYCLE_BIN_RETENTION_DAYS` (`vault.service.ts:50-56`, `vault.controller.ts:58`, `vault-config.dto.ts:11`). Dead backend surface, non-functional — remove or document as intentionally retained.
3. **D-04 — preset buttons / cooldown dropdown (cosmetic).** Plain number inputs shipped instead of 7/14/30/90 presets + 5m/15m/30m/1h/off dropdown. Sanctioned by the executed 39-04 plan and CONTEXT "Claude discretion"; all settings remain editable/validated.
