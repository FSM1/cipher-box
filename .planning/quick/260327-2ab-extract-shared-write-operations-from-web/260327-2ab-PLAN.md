SharedWriteContext type definition:

```typescript
type SharedWriteContext = {
  ctx: SdkContext;
  folderKey: Uint8Array;
  ipnsPrivateKey: Uint8Array;
  ipnsName: string;
  sequenceNumber: bigint;
  children: FolderChild[];
  ownerPublicKey: Uint8Array; // sharer's secp256k1 pubkey (keys wrap for owner)
  recipientPublicKey: Uint8Array; // current user's pubkey (keys wrap for recipient)
  shareId: string; // for addShareKeysFn calls
  addShareKeysFn: (
    shareId: string,
    keys: Array<{ keyType: string; itemId: string; encryptedKey: string }>
  ) => Promise<void>;
};

Function 1 -- `uploadToSharedFolder(swCtx, params: { data: Uint8Array, fileName: string, mimeType?: string })`:

- Use `@cipherbox/crypto` directly (encryptAesGcm, generateFileKey, generateIv, wrapKey) for file encryption (same as the hook does -- sdk-core's uploadFile wraps with user's own pubkey, but shared uploads need owner's pubkey)
- Upload encrypted content via `addToIpfs(ctx, ciphertext)`
- Wrap fileKey with ownerPublicKey for FilePointer.fileKeyEncrypted
- Generate IPNS keypair via `generateFileIpnsKeypair()` from @cipherbox/core
- Wrap IPNS private key with ownerPublicKey (for FilePointer) AND recipientPublicKey (for share_keys)
- Create + encrypt FileMetadata, upload to IPFS, create IPNS record via sdk-core's `batchPublishIpnsRecords`
- Build FilePointer, append to children, publish parent folder via `updateFolderMetadataAndPublish`
- Call addShareKeysFn for recipient file + file-ipns keys
- Zero fileKey and ipnsKeypair.privateKey in finally
- Return { updatedChildren, newSequenceNumber, filePointer }

Function 2 -- `createSharedSubfolder(swCtx, params: { name: string })`:

- Use sdk-core's `createSubfolder` but override the userPublicKey to be ownerPublicKey (keys in FolderEntry wrap for owner, not recipient). createSubfolder wraps with the provided userPublicKey, so pass ownerPublicKey.
- Create empty folder metadata, encrypt with subfolderKey, upload to IPFS
- Publish subfolder IPNS via `createAndPublishIpnsRecord`
- Append FolderEntry to children, publish parent folder via `updateFolderMetadataAndPublish`
- Wrap subfolderKey and ipnsPrivateKey with recipientPublicKey for share_keys (folder + folder-ipns)
- Call addShareKeysFn
- Zero subfolderKey and ipnsPrivateKey in finally
- Return { updatedChildren, newSequenceNumber, folderEntry }

Function 3 -- `renameInSharedFolder(swCtx, params: { itemId: string, newName: string })`:

- Map over children: if id matches, update name + modifiedAt
- Publish via `updateFolderMetadataAndPublish`
- Return { updatedChildren, newSequenceNumber }

Function 4 -- `deleteFromSharedFolder(swCtx, params: { itemId: string })`:

- Filter item from children
- Publish via `updateFolderMetadataAndPublish`
- Return { updatedChildren, newSequenceNumber }

Function 5 -- `updateSharedFile(params: { ctx, folderKey, ownerPublicKey, recipientPublicKey, shareId, addShareKeysFn, filePointer: FilePointer, newContent: Uint8Array, getFileIpnsKeyFn: (itemId) => Promise<Uint8Array | null> })`:

- Note: Does NOT need full SharedWriteContext since it doesn't modify folder metadata

- Resolve current file metadata via `resolveFileMetadata` from sdk-core
- Update file metadata via `updateFileMetadata` from sdk-core
- Batch publish file IPNS record via `batchPublishIpnsRecords`
- Call addShareKeysFn for updated recipient file key
- Zero fileKey and ipnsPrivKey in finally

Function 6 -- `updateSharePermission(params: { shareId, permission, encryptedIpnsKey?, updatePermissionFn })`:

const buildSharedWriteCtx = useCallback((): SharedWriteContext | null => {
  const currentIpnsKey = ipnsPrivateKeyRef.current;
  const auth = useAuthStore.getState();
  if (
    !currentIpnsKey ||
    !folderKey ||
    !ipnsName ||
    currentSequenceNumber === null ||
    !auth.vaultKeypair
  )
    return null;

  const shareItem = sharedItems.find((s) => s.share.shareId === currentShareId);
  if (!shareItem) return null;
  const ownerPubKey = parsePublicKey(shareItem.share.sharerPublicKey);

  return {
    ctx: {
      apiUrl: AUTH_API_URL,
      getAccessToken: () => getAccessToken(),
      axiosInstance: getAxiosInstance(),
    },
    folderKey,
    ipnsPrivateKey: currentIpnsKey,
    ipnsName,
    sequenceNumber: currentSequenceNumber,
    children: folderChildrenRef.current,
    ownerPublicKey: ownerPubKey,
    recipientPublicKey: auth.vaultKeypair.publicKey,
    shareId: currentShareId!,
    addShareKeysFn: async (sid, keys) => {
      await addShareKeys(sid, keys);
      shareKeysCache.current.delete(sid);
    },
  };
}, [...deps]);
```
