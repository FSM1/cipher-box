<objective>
Fix GAP-2 (MODERATE): Windows desktop deletes bypass the recycle bin entirely. The macOS/Linux
FUSE `handle_unlink`/`handle_rmdir` call `spawn_bin_entry_publish()` to create bin entries on
delete. The Windows WinFsp `handle_cleanup` with `FspCleanupDelete` flag does NOT create bin
entries -- files are permanently deleted without bin protection.

Purpose: Windows users get the same recycle bin soft-delete behavior as macOS/Linux users.
Output: handle_cleanup creates BinEntry and calls spawn_bin_entry_publish when FspCleanupDelete is set.
</objective>

  <action>
    Port the bin entry creation logic from macOS/Linux `handle_unlink` and `handle_rmdir`
    (in `apps/desktop/src-tauri/src/fuse/write_ops.rs`) into the Windows `handle_cleanup`
    (in `apps/desktop/src-tauri/src/fuse/windows/write_ops.rs`).

    Currently, when `flags & 0x01 != 0` (FspCleanupDelete), `handle_cleanup`:
    1. Gets parent_ino and cid_to_unpin from the inode
    2. Removes the inode
    3. Updates parent metadata
    4. Unpins the CID directly (bypassing bin)

    The fix replaces the direct CID unpin (step 4) with bin entry creation. The CID stays pinned
    for recovery; it will be unpinned at permanent-delete time.

    **Implementation:**

    Before `fs.inodes.remove(ino)`, capture bin entry data from the inode (similar to macOS/Linux):

    ```rust
    // Capture data for bin entry before inode removal
    let bin_entry_data = match fs.inodes.get(ino) {
        Some(inode) => match &inode.kind {
            InodeKind::File {
                file_meta_ipns_name,
                file_ipns_key_encrypted_hex,
                size,
                cid,
                ..
            } => {
                let now_ms = SystemTime::now()
                    .duration_since(UNIX_EPOCH)
                    .unwrap_or_default()
                    .as_millis() as u64;
                let created_ms = inode.attr.crtime
                    .duration_since(UNIX_EPOCH)
                    .unwrap_or_default()
                    .as_millis() as u64;

                match file_meta_ipns_name {
                    Some(name) if !name.is_empty() => {
                        let file_pointer = crate::crypto::folder::FilePointer {
                            id: crate::crypto::utils::generate_uuid_v4(),
                            name: inode.name.clone(),
                            file_meta_ipns_name: name.clone(),
                            ipns_private_key_encrypted: file_ipns_key_encrypted_hex.clone(),
                            created_at: if created_ms > 0 { created_ms } else { now_ms },
                            modified_at: now_ms,
                        };
                        Some(BinEntryData::File {
                            name: inode.name.clone(),
                            size: *size,
                            content_cid: if cid.is_empty() { None } else { Some(cid.clone()) },
                            file_pointer,
                        })
                    }
                    _ => {
                        log::warn!(
                            "cleanup delete: missing file_meta_ipns_name for ino {}, skipping bin entry",
                            ino
                        );
                        None
                    }
                }
            }
            InodeKind::Folder {
                ipns_name,
                encrypted_folder_key,
                ipns_private_key,
                ..
            } => {
                let now_ms = SystemTime::now()
                    .duration_since(UNIX_EPOCH)
                    .unwrap_or_default()
                    .as_millis() as u64;
                let created_ms = inode.attr.crtime
                    .duration_since(UNIX_EPOCH)
                    .unwrap_or_default()
                    .as_millis() as u64;

                match ipns_private_key {
                    Some(key) => {
                        match crate::crypto::ecies::wrap_key(key, &fs.public_key) {
                            Ok(wrapped) => {
                                let folder_entry = crate::crypto::folder::FolderEntry {
                                    id: crate::crypto::utils::generate_uuid_v4(),
                                    name: inode.name.clone(),
                                    ipns_name: ipns_name.clone(),
                                    folder_key_encrypted: encrypted_folder_key.clone(),
                                    ipns_private_key_encrypted: hex::encode(&wrapped),
                                    created_at: if created_ms > 0 { created_ms } else { now_ms },
                                    modified_at: now_ms,
                                };
                                Some(BinEntryData::Folder {
                                    name: inode.name.clone(),
                                    folder_entry,
                                })
                            }
                            Err(e) => {
                                log::error!("cleanup delete: failed to wrap IPNS key: {}", e);
                                None
                            }
                        }
                    }
                    None => {
                        log::error!("cleanup delete: missing IPNS private key for ino {}", ino);
                        None
                    }
                }
            }
            _ => None,
        },
        None => None,
    };
    ```

    Use a local enum or tuple variants to distinguish file vs folder bin data. You can use
    a simple approach without a local enum -- just use two separate Option variables:
    `bin_file_data: Option<(String, u64, Option<String>, FilePointer)>` and
    `bin_folder_data: Option<(String, FolderEntry)>`, similar to how the macOS/Linux code
    does it with separate match arms.

    After `fs.inodes.remove(ino)` and `fs.update_folder_metadata(parent_ino)`, replace the
    direct CID unpin block with bin entry creation:

    ```rust
    // Create bin entry and publish (fire-and-forget) -- replaces direct CID unpin
    let parent_ipns_name = fs.inodes.get(parent_ino)
        .map(|p| match &p.kind {
            InodeKind::Root { ipns_name, .. } => ipns_name.clone().unwrap_or_default(),
            InodeKind::Folder { ipns_name, .. } => ipns_name.clone(),
            _ => String::new(),
        })
        .unwrap_or_default();

    if !parent_ipns_name.is_empty() {
        let parent_path = build_folder_path(&fs, parent_ino);
        let now_ms = SystemTime::now()
            .duration_since(UNIX_EPOCH)
            .unwrap_or_default()
            .as_millis() as u64;

        let bin_entry = if let Some((name, size, content_cid, fp)) = bin_file_data {
            Some(crate::crypto::bin::BinEntry {
                id: crate::crypto::utils::generate_uuid_v4(),
                item_type: crate::crypto::bin::BinItemType::File,
                name,
                original_parent_ipns_name: parent_ipns_name,
                original_path: parent_path,
                deleted_at: now_ms,
                size,
                mime_type: crate::crypto::utils::mime_from_extension(&fp.name).to_string(),
                file_pointer: Some(fp),
                folder_entry: None,
                content_cid,
                content_size: Some(size),
            })
        } else if let Some((name, fe)) = bin_folder_data {
            Some(crate::crypto::bin::BinEntry {
                id: crate::crypto::utils::generate_uuid_v4(),
                item_type: crate::crypto::bin::BinItemType::Folder,
                name,
                original_parent_ipns_name: parent_ipns_name,
                original_path: parent_path,
                deleted_at: now_ms,
                size: 0,
                mime_type: String::new(),
                file_pointer: None,
                folder_entry: Some(fe),
                content_cid: None,
                content_size: None,
            })
        } else {
            None
        };

        if let Some(entry) = bin_entry {
            crate::fuse::spawn_bin_entry_publish(
                fs.api.clone(),
                fs.rt.clone(),
                entry,
                fs.private_key.clone(),
                fs.public_key.to_vec(),
                fs.publish_coordinator.clone(),
            );
        }
    }
    ```
