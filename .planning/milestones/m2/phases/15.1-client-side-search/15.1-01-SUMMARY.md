## Decisions Made

- **Raw IndexedDB API over idb library** -- existing codebase (device/identity.ts) uses raw IndexedDB with the same number[] serialization pattern; consistency over convenience
- **HKDF info string "cipherbox-search-index-v1"** -- domain separation from other keys derived from the same vault private key (vault IPNS uses "cipherbox-vault-ipns-v1")
- **Web Crypto API directly for HKDF + AES-GCM** -- HKDF derivation produces a CryptoKey; using @cipherbox/crypto's encryptAesGcm would require raw key bytes, adding unnecessary conversion
- **Deduplication in buildFromFolderTree** -- folder children and folder-self entries can overlap (subfolder appears both as parent's child and as its own folder entry); Map-based dedup keeps the last entry
