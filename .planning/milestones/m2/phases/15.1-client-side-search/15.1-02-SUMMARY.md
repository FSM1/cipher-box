## Decisions Made

- **Module-level callback registration for cross-component events** -- registerRebuildCallback/triggerSearchIndexRebuild pattern avoids prop drilling from AppShell through children slot to FileBrowser; simpler than Zustand store or context for a single callback
- **Auth state transition watcher for logout cleanup** -- useRef tracking previous isAuthenticated value detects true->false transition; self-contained within useSearch hook, no external wiring needed
- **Unicode file type icons** -- getFileIcon returns Unicode characters (folder/file/image/video/doc symbols) consistent with terminal aesthetic; no additional icon library dependency
