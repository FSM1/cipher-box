<objective>
Create the search index service that powers client-side file/folder name search. This service manages a MiniSearch instance for fuzzy text matching, encrypts the serialized index with AES-256-GCM before persisting to IndexedDB, and provides methods for building, updating, querying, and clearing the index.

Purpose: Data layer foundation for SRCH-01 (search across all folders), SRCH-02 (encrypted persistence), and SRCH-03 (incremental updates). Without this service, the search UI has nothing to query.

Output: `apps/web/src/services/search-index.service.ts` -- a standalone service with no React dependencies (pure TypeScript class).

<task type="auto">
  <name>Task 2: Create SearchIndexService</name>
  <files>apps/web/src/services/search-index.service.ts</files>
  <action>
    Create a standalone TypeScript class `SearchIndexService` in `apps/web/src/services/search-index.service.ts`. This service has NO React dependencies -- it's a pure service class that can be instantiated and used by hooks.

    **Data model for indexed documents:**

    ```typescript
    type SearchDocument = {
      id: string;          // unique key: `${folderId}:${childId}` (avoids collisions across folders)
      name: string;        // file or folder name (what users search for)
      type: 'file' | 'folder';
      parentPath: string;  // breadcrumb path like "My Vault / Documents / Reports"
      parentFolderId: string; // folder ID for navigation on result click
      modifiedAt: number;  // timestamp for display in results
    };
    ```

    **MiniSearch configuration:**

    ```typescript
    const miniSearch = new MiniSearch<SearchDocument>({
      fields: ['name'],           // only index file/folder names
      storeFields: ['name', 'type', 'parentPath', 'parentFolderId', 'modifiedAt'],
      searchOptions: {
        fuzzy: 0.2,               // fuzzy matching threshold
        prefix: true,             // prefix matching (typing 'rep' matches 'report')
        boost: { name: 1 },      // single field, no boost needed but explicit
      },
    });
    ```

    **Class API:**

    ```typescript
    export class SearchIndexService {
      private miniSearch: MiniSearch<SearchDocument>;
      private indexVersion: number = 0;  // increments on each rebuild, used for cache invalidation

      constructor();

      /** Build the full index from the folder store's folder tree.
       *  Walks all loaded FolderNodes and indexes their children (files and folders).
       *  @param folders - Record<string, FolderNode> from folder store
       */
      buildFromFolderTree(folders: Record<string, FolderNode>): void;

      /** Search the index with fuzzy matching.
       *  @param query - user's search string
       *  @returns Array of SearchResult (SearchDocument + score + match info)
       */
      search(query: string): SearchResult[];

      /** Persist the current index to IndexedDB, encrypted with the provided key.
       *  Derives an AES-256 key from the user's vault private key using HKDF
       *  with info "cipherbox-search-index-v1".
       *  Serializes the MiniSearch index to JSON, encrypts with AES-256-GCM,
       *  stores { iv: number[], data: number[] } in IndexedDB.
       *  @param userPrivateKey - user's secp256k1 private key (32 bytes) for HKDF derivation
       */
      persistEncrypted(userPrivateKey: Uint8Array): Promise<void>;

      /** Load the index from IndexedDB and decrypt.
       *  @param userPrivateKey - user's secp256k1 private key (32 bytes) for HKDF derivation
       *  @returns true if index was loaded successfully, false if not found or decryption failed
       */
      loadEncrypted(userPrivateKey: Uint8Array): Promise<boolean>;

      /** Clear the in-memory index and remove from IndexedDB. Call on logout. */
      clear(): Promise<void>;

      /** Returns whether the index has any documents */
      get isEmpty(): boolean;

      /** Returns the number of indexed documents */
      get size(): number;
    }
    ```

    **SearchResult type:**

    ```typescript
    export type SearchResult = {
      id: string;
      name: string;
      type: 'file' | 'folder';
      parentPath: string;
      parentFolderId: string;
      modifiedAt: number;
      score: number;
      match: Record<string, string[]>;  // from MiniSearch, for highlight info
    };
    ```

    **buildFromFolderTree implementation details:**

    1. Clear existing index (`miniSearch.removeAll()`)
    2. Walk all FolderNodes in the `folders` record
    3. For each folder, build the parent path by walking up parentId chain to root
    4. For each child in `folder.children`:
       - Create a SearchDocument with `id: ${folder.id}:${child.id}`, `name: child.name`, `type: child.type`, `parentPath`, `parentFolderId: folder.id`, `modifiedAt: child.modifiedAt ?? child.createdAt ?? 0`
    5. Also index the folders themselves (except root): for each FolderNode, add a document with the folder's own name, its parentId as parentFolderId, and its parent's path
    6. Batch add all documents via `miniSearch.addAll(documents)`
    7. Increment `indexVersion`

    **Path building helper:**

    ```typescript
    private buildPath(folderId: string, folders: Record<string, FolderNode>): string {
      const parts: string[] = [];
      let currentId: string | null = folderId;
      while (currentId) {
        const folder = folders[currentId];
        if (!folder) break;
        parts.unshift(folder.name);
        currentId = folder.parentId;
      }
      return parts.join(' / ');
    }
    ```

    **IndexedDB persistence (follow existing pattern from device/identity.ts):**

    - DB name: `cipherbox-search`
    - DB version: 1
    - Store name: `index`
    - Key: `encrypted-index`
    - Stored value: `{ iv: number[], data: number[] }` (number arrays for cross-browser IndexedDB compat, same pattern as device identity)

    **Encryption approach:**

    Use HKDF to derive a dedicated AES-256 key from the user's vault private key:
    - Import user's 32-byte private key as HKDF base key material
    - Use HKDF with SHA-256, no salt, info: "cipherbox-search-index-v1"
    - Derive 256-bit AES-GCM key
    - Generate random 12-byte IV for each encryption
    - Encrypt the JSON-serialized MiniSearch index

    Use Web Crypto API directly for HKDF + AES-GCM (not the @cipherbox/crypto encryptAesGcm which expects a raw Uint8Array key). The HKDF derivation ensures the search index key is domain-separated from other keys derived from the same private key.

    ```typescript
    private async deriveSearchKey(userPrivateKey: Uint8Array): Promise<CryptoKey> {
      const baseKey = await crypto.subtle.importKey(
        'raw', userPrivateKey, 'HKDF', false, ['deriveKey']
      );
      return crypto.subtle.deriveKey(
        { name: 'HKDF', hash: 'SHA-256', salt: new Uint8Array(0), info: new TextEncoder().encode('cipherbox-search-index-v1') },
        baseKey,
        { name: 'AES-GCM', length: 256 },
        false,
        ['encrypt', 'decrypt']
      );
    }
    ```

    **Important constraints:**
    - Do NOT copy or reference the user's private key beyond the HKDF derivation call. The key is used transiently.
    - Serialization: use `miniSearch.toJSON()` for serialization and `MiniSearch.loadJSON()` for deserialization. Pass the same options object to `loadJSON`.
    - The service is a singleton-style class (one instance per app session). Export a module-level instance: `export const searchIndexService = new SearchIndexService();`
    - On `clear()`, call `miniSearch.removeAll()`, then delete the IndexedDB entry.
    - Handle IndexedDB errors gracefully (try/catch, return false on load failure). Search should work even if persistence fails.

    **Export from services/index.ts:** Add `export { searchIndexService, type SearchResult } from './search-index.service';` to `apps/web/src/services/index.ts`.
