Create `tests/e2e/tests/search-workflow.spec.ts` following the established pattern from `full-workflow.spec.ts` and `invite-link-workflow.spec.ts`.

**Test structure:** Use `test.describe.serial('Search Workflow', ...)` with a single login session. The test user's vault must have at least one file to search for.

**Imports:**

- `test, expect` from `@playwright/test`
- `loginViaEmail, TEST_CREDENTIALS` from `../utils/web3auth-helpers`
- `createTestTextFile, cleanupTestFiles` from `../utils/test-files`
- `FileListPage` from `../page-objects/file-browser/file-list.page`
- `UploadZonePage` from `../page-objects/file-browser/upload-zone.page`
- `SearchPalettePage` from `../page-objects/dialogs/search-palette.page`

**Setup phase:**

- `test('0.1 Login and create test content', ...)` -- Login via `loginViaEmail(page, TEST_CREDENTIALS.email)`. Wait for `/files`. Upload a uniquely named text file (use `Date.now()` for uniqueness, e.g., `search-test-${runId}.txt`). Wait for the file to appear in the file list via `FileListPage.waitForItemToAppear()`.

**Test cases (each is a serial test):**

1. **`test('1.1 Open search palette via Cmd+K', ...)`**
   - Press `Meta+k` (macOS) via `page.keyboard.press('Meta+k')`
   - Verify palette opens: `searchPalette.waitForOpen()`
   - Verify input is focused: `await expect(searchPalette.input()).toBeFocused()`
   - Close via Escape: `page.keyboard.press('Escape')`
   - Verify palette closes: `searchPalette.waitForClosed()`

2. **`test('1.2 Open search palette via header button', ...)`**
   - Click `searchPalette.headerSearchButton()`
   - Verify palette opens: `searchPalette.waitForOpen()`
   - Verify input is focused
   - Close via Escape for cleanup

3. **`test('2.1 Type query and verify results appear', ...)`**
   - Open palette via `Meta+k`
   - Type the first 6+ characters of the uploaded test file name via `searchPalette.typeQuery()`
   - Wait for results: `searchPalette.waitForResults({ timeout: 10000 })` (index build + search debounce may take a moment on first open)
   - Verify result count > 0: `expect(await searchPalette.getResultCount()).toBeGreaterThan(0)`
   - Verify result names include the test file: `const names = await searchPalette.getResultNames(); expect(names.some(n => n.includes(testFileName))).toBe(true)`
   - Verify footer count text is visible and shows a number: `const countText = await searchPalette.getFooterCountText(); expect(countText).toMatch(/\d+ result/)`
   - Close via Escape

4. **`test('2.2 No results for nonsense query', ...)`**
   - Open palette via `Meta+k`
   - Type `'zzzzxqwnofile999'`
   - Wait 500ms for debounce
   - Verify no results: `expect(await searchPalette.getResultCount()).toBe(0)`
   - Verify "no results" message visible: `await expect(searchPalette.noResults()).toBeVisible()`
   - Close via Escape

5. **`test('3.1 Select result and verify navigation', ...)`**
   - Open palette via `Meta+k`
   - Type query matching the test file
   - Wait for results
   - Click the first result: `searchPalette.clickResult(0)`
   - Verify palette closes: `searchPalette.waitForClosed()`
   - Verify URL is on `/files` (root folder since file was uploaded to root): `await page.waitForURL('**/files', { timeout: 10000 })`
   - Verify the file is visible in the file list (confirming navigation landed correctly)

6. **`test('3.2 Keyboard navigation with Enter selects result', ...)`**
   - Open palette via `Meta+k`
   - Type query matching the test file
   - Wait for results
   - Press `ArrowDown` then `Enter` (or just `Enter` if first result is auto-selected)
   - Verify palette closes
   - Verify URL is on `/files`

7. **`test('4.1 Escape closes palette', ...)`**
   - Open palette via `Meta+k`
   - Type some text
   - Press `Escape`
   - Verify palette closes: `searchPalette.waitForClosed()`

8. **`test('4.2 Click outside closes palette', ...)`**
   - Open palette via `Meta+k`
   - Click the backdrop (not the palette): `page.locator('.search-backdrop').click({ position: { x: 10, y: 10 } })` -- clicking near top-left of backdrop, outside the centered palette
   - Verify palette closes: `searchPalette.waitForClosed()`

9. **`test('9.1 Cleanup', ...)`**
   - Call `cleanupTestFiles()`

**Important implementation notes:**

- Use `Control+k` as fallback if `Meta+k` doesn't work (for CI Linux runners). Pattern: `page.keyboard.press('Control+k')`. Actually, use `page.keyboard.press(process.platform === 'darwin' ? 'Meta+k' : 'Control+k')` -- but since Playwright config only targets Chromium desktop, and CI may be Linux, use `Meta+k` first and if that fails, try `Control+k`. Simpler: Playwright runs in a browser context where `Meta` maps to OS key. Just use `Meta+k` which Playwright sends as the correct modifier.
- The search index builds on first palette open, which can take a few seconds. The `waitForResults` should have a generous timeout (10s) for the first search.
- After typing a query, there's a 150ms debounce before results appear. Use `waitForResults` rather than `waitForTimeout`.
- For click-outside test, the backdrop is the full-screen overlay. The palette is centered and ~600px wide. Clicking at position {x: 10, y: 10} of the backdrop element will be outside the palette.
