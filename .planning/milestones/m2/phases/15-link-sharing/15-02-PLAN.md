<objective>
Regenerate the API client, extract shared crypto utilities, and build the frontend invite service with ephemeral key bridge cryptography.

Purpose: Provides the typed API integration and crypto logic needed by the UI components. The ephemeral key bridge is the core security innovation: wrap with ephemeral pubkey, put ephemeral privkey in URL fragment, recipient unwraps and re-wraps with their own key. Extracting collectChildKeys to a shared utility prevents duplication between ShareDialog and invite service.

Output: Generated Orval client for invite endpoints + shared key-wrapping utilities + invite.service.ts with createInviteLink, claimInvite, and management functions.
</objective>

<task type="auto">
  <name>Task 2: Frontend invite service with ephemeral key bridge</name>
  <files>
    apps/web/src/services/invite.service.ts
  </files>
  <action>
    Create `invite.service.ts` with the following functions. Use the Orval-generated client function names from Task 1 (check the actual generated output).

    **1. `generateEphemeralKeypair()`:**
    - Import `@noble/secp256k1` (already in web app dependencies)
    - Generate: `const privateKey = secp256k1.utils.randomPrivateKey()`
    - Derive: `const publicKey = secp256k1.getPublicKey(privateKey, false)` (uncompressed, 65 bytes)
    - Return `{ privateKey: Uint8Array, publicKey: Uint8Array, privateKeyHex: string }`
    - Use `bytesToHex` from `@cipherbox/crypto` for hex conversion

    **2. `buildInviteUrl(token: string, ephemeralPrivKeyHex: string): string`:**
    - Format: `${window.location.origin}${window.location.pathname}#/invite/${token}?key=${ephemeralPrivKeyHex}`
    - The entire path after `#` is the hash fragment -- never sent to server
    - This is critical: HashRouter uses `#` for routing, so the `?key=` is WITHIN the fragment

    **3. `async createInviteLink(params: { item, folderKey, ipnsName, parentFolderId }): Promise<{ url: string, token: string }>`:**
    - Generate ephemeral keypair
    - Import `collectChildKeys` from `../lib/crypto/key-wrapping` (the shared utility extracted in Task 1)
    - If item is a folder:
      - Unwrap the folder's own key from `folderEntry.folderKeyEncrypted` using owner's privateKey
      - Wrap the folder key with ephemeral PUBLIC key: `wrapKey(folderKey, ephemeralKeypair.publicKey)`
      - Collect child keys using the shared `collectChildKeys` function, passing ephemeral pubkey as the target key
    - If item is a file:
      - Wrap parent folder key with ephemeral PUBLIC key (needed for file metadata decryption)
      - Resolve file metadata, wrap file key with ephemeral PUBLIC key as child key
    - Call create invite API endpoint (on ShareInvitesController) with: itemType, ipnsName, itemName, encryptedKey (hex), encryptedChildKeys (array)
    - Build invite URL with token + ephemeral private key hex
    - Zero ephemeral private key from memory: `ephemeralKeypair.privateKey.fill(0)`
    - Return { url, token }

    **4. `async claimInvite(token: string, ephemeralPrivKeyHex: string): Promise<{ shareId: string }>`:**
    - Fetch full invite data from `GET /invites/:token/data` (the authenticated endpoint on InvitesController that returns encryptedKey + encryptedChildKeys). Use the Orval-generated function for this endpoint (e.g., `invitesControllerGetInviteData(token)`).
    - Get vault keypair from auth store: `useAuthStore.getState().vaultKeypair`
    - Parse ephemeral private key: `hexToBytes(ephemeralPrivKeyHex)`
    - Unwrap item key: `unwrapKey(hexToBytes(invite.encryptedKey), ephemeralPrivKey)`
    - Re-wrap with own public key: `wrapKey(plaintextKey, vaultKeypair.publicKey)`
    - Zero plaintext key: `plaintextKey.fill(0)`
    - Repeat for each child key in `encryptedChildKeys`
    - Zero ephemeral private key: `ephemeralPrivKey.fill(0)`
    - Call claim API endpoint (POST /invites/:token/claim) with re-wrapped keys
    - Return { shareId }
    - Use try/finally for key zeroing to ensure cleanup even on errors

    **5. `async fetchInvitesForItem(ipnsName: string): Promise<InviteInfo[]>`:**
    - Call list invites API (GET /shares/invites on ShareInvitesController) with ipnsName query param
    - Map response to typed InviteInfo objects
    - Type: `{ id, token, status, expiresAt, createdAt }`

    **6. `async revokeInvite(inviteId: string): Promise<void>`:**
    - Call revoke API endpoint (DELETE /shares/invites/:inviteId on ShareInvitesController)

    **7. `async checkInviteStatus(token: string): Promise<'active' | 'expired' | 'claimed' | 'revoked'>`:**
    - Call the public GET /invites/:token endpoint (on InvitesController)
    - Return status string
    - Handle 404/errors as 'expired'

    CRITICAL NOTES:
    - Memory safety: ALL ephemeral key bytes and plaintext key bytes must be zeroed in `finally` blocks.
    - Import `hexToBytes`, `bytesToHex`, `wrapKey`, `unwrapKey` from `@cipherbox/crypto`
    - Import `collectChildKeys` from `../lib/crypto/key-wrapping` (shared utility)
