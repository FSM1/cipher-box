  <action>
  Create `.github/workflows/e2e-desktop.yml` with the following structure:

**Name:** `Desktop E2E Tests`

**Triggers:**

```yaml
on:
  workflow_run:
    workflows: ['CI']
    types: [completed]
    branches: [main]
  workflow_dispatch:
    inputs:
      run_id:
        description: 'CI workflow run ID to download artifacts from (optional, uses latest if empty)'
        required: false
        type: string
```

**Permissions:**

```yaml
permissions:
  actions: read # needed for cross-workflow artifact download
```

**Job: e2e-desktop**

```yaml
jobs:
  e2e-desktop:
    name: Desktop E2E (${{ matrix.platform }})
    if: >-
      github.event_name == 'workflow_dispatch' ||
      (github.event_name == 'workflow_run' && github.event.workflow_run.conclusion == 'success')
    runs-on: ${{ matrix.os }}
    timeout-minutes: 30
    strategy:
      fail-fast: false
      matrix:
        include:
          - platform: macos
            os: macos-latest
            artifact: desktop-debug-macos
            fuse-feature: fuse
            shell: bash
          - platform: windows
            os: windows-latest
            artifact: desktop-debug-windows
            fuse-feature: winfsp
            shell: powershell
          - platform: linux
            os: ubuntu-22.04
            artifact: desktop-debug-linux
            fuse-feature: fuse
            shell: bash
```

**Steps (in order):**

1. **Checkout** -- `actions/checkout@v4`

2. **Download debug binary** -- Use `actions/download-artifact@v4` with:
   - `name: ${{ matrix.artifact }}`
   - `path: desktop-binary/`
   - `run-id: ${{ inputs.run_id || github.event.workflow_run.id }}`
   - `github-token: ${{ secrets.GITHUB_TOKEN }}`
     If `workflow_dispatch` without `run_id`, we need the latest CI run. Use a step that finds it:

   ```yaml
   - name: Find latest CI run ID
     if: github.event_name == 'workflow_dispatch' && inputs.run_id == ''
     id: find-run
     run: |
       RUN_ID=$(gh run list --workflow=ci.yml --branch=main --status=success --limit=1 --json databaseId --jq '.[0].databaseId')
       echo "run_id=$RUN_ID" >> $GITHUB_OUTPUT
     env:
       GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
   ```

   Then the download step uses: `run-id: ${{ inputs.run_id || steps.find-run.outputs.run_id || github.event.workflow_run.id }}`

3. **Make binary executable** (non-Windows only):

   ```yaml
   - name: Make binary executable
     if: runner.os != 'Windows'
     run: chmod +x desktop-binary/cipherbox-desktop
   ```

4. **Install PostgreSQL** -- `ikalnytskyi/action-setup-postgres@v8`:

   ```yaml
   - name: Setup PostgreSQL
     uses: ikalnytskyi/action-setup-postgres@v8
     with:
       username: postgres
       password: postgres
       database: cipherbox_test
       postgres-version: '16'
     id: postgres
   ```

5. **Install Kubo (IPFS)** -- platform-conditional:
   - macOS/Linux: Download `kubo_v0.34.0_{arch}.tar.gz` from dist.ipfs.tech, extract, install, init, start daemon. Auto-detect architecture (`uname -m` -> map arm64 to arm64, x86_64 to amd64). Poll `curl -s http://localhost:5001/api/v0/id` for readiness.
   - Windows (PowerShell): Download zip, extract, add to PATH, init, start as background process. Poll for readiness.

6. **Install Redis** -- platform-conditional:
   - macOS: `brew install redis && brew services start redis`
   - Linux: `sudo apt-get update && sudo apt-get install -y redis-server && sudo systemctl start redis-server`
   - Windows: `choco install redis-64 -y` then `Start-Process redis-server -NoNewWindow` then `Start-Sleep -Seconds 3`

7. **Install FUSE driver** -- platform-conditional:
   - macOS: `brew install --cask fuse-t` (already proven in ci.yml)
   - Linux: `sudo apt-get install -y libfuse3-dev fuse3` (plus `sudo modprobe fuse` if needed). Also install Tauri webview deps: `libwebkit2gtk-4.1-0 libayatana-appindicator3-1`
   - Windows: Download WinFsp MSI, verify SHA-256 hash, install silently. Copy exact pattern from ci.yml `build-desktop-windows` job (lines 469-480).

8. **Setup Node.js + pnpm:**

   ```yaml
   - uses: pnpm/action-setup@v4
     with:
       version: 10
   - uses: actions/setup-node@v4
     with:
       node-version: '22'
       cache: 'pnpm'
   ```

9. **Install dependencies and build API:**

   ```yaml
   - name: Install dependencies
     run: pnpm install --frozen-lockfile
   - name: Build mock-ipns-routing
     run: cd tools/mock-ipns-routing && npm install && npm run build
   - name: Build packages
     run: pnpm --filter @cipherbox/crypto --filter @cipherbox/api build
   ```

10. **Create .env files:**
    Create `apps/api/.env` with ALL required vars:
    - NODE_ENV=test
    - DB_HOST=localhost, DB_PORT=5432, DB_USERNAME=postgres, DB_PASSWORD=postgres, DB_DATABASE=cipherbox_test
    - JWT_SECRET=e2e-desktop-jwt-secret-key
    - CORS_ALLOWED_ORIGINS=http://localhost:5173
    - IPFS_PROVIDER=local, IPFS_LOCAL_API_URL=http://localhost:5001, IPFS_LOCAL_GATEWAY_URL=http://localhost:8080
    - DELEGATED_ROUTING_URL=http://localhost:3001
    - REDIS_HOST=localhost, REDIS_PORT=6379
    - TEST_LOGIN_SECRET=e2e-test-secret-ci-only
    - IDENTITY_JWT_PRIVATE_KEY=${{ secrets.IDENTITY_JWT_PRIVATE_KEY }}

    Create `apps/desktop/.env`:
    - VITE_API_URL=http://localhost:3000
    - VITE_TEST_LOGIN_SECRET=e2e-test-secret-ci-only

11. **Run migrations:**
    `pnpm --filter @cipherbox/api migration:run` with DB env vars

12. **Start API + mock-ipns-routing in background:**

    ```yaml
    - name: Start API server
      run: |
        cd apps/api
        node dist/main.js &
        # Wait for API readiness
        for i in $(seq 1 30); do
          if curl -s http://localhost:3000/health > /dev/null 2>&1; then
            echo "API ready"
            break
          fi
          sleep 1
        done
      env:
        NODE_ENV: test
        # ... (all DB/IPFS/Redis env vars)
    ```

    Windows version uses `Start-Process` and `Invoke-WebRequest` polling.

    Also start mock-ipns-routing:

    ```yaml
    - name: Start mock IPNS routing
      run: node tools/mock-ipns-routing/dist/index.js &
    ```

13. **Launch desktop binary + run tests:**
    - macOS/Linux:

      ```yaml
      - name: Run desktop E2E tests
        if: runner.os == 'Linux'
        uses: GabrielBB/xvfb-action@v1
        with:
          run: |
            export CIPHERBOX_API_URL=http://localhost:3000
            export VITE_API_URL=http://localhost:3000
            export VITE_TEST_LOGIN_SECRET=e2e-test-secret-ci-only
            export RUST_LOG=info
            DEV_KEY=$(openssl rand -hex 32)
            ./desktop-binary/cipherbox-desktop --dev-key $DEV_KEY &
            DESKTOP_PID=$!
            bash tests/e2e-desktop/scripts/run-all.sh
            TEST_EXIT=$?
            kill $DESKTOP_PID 2>/dev/null || true
            # Unmount
            if [ "$(uname)" = "Darwin" ]; then
              diskutil unmount force ~/CipherBox 2>/dev/null || true
            else
              fusermount3 -u ~/CipherBox 2>/dev/null || true
            fi
            exit $TEST_EXIT

      - name: Run desktop E2E tests (macOS)
        if: runner.os == 'macOS'
        run: |
          export CIPHERBOX_API_URL=http://localhost:3000
          export VITE_API_URL=http://localhost:3000
          export VITE_TEST_LOGIN_SECRET=e2e-test-secret-ci-only
          export RUST_LOG=info
          DEV_KEY=$(openssl rand -hex 32)
          ./desktop-binary/cipherbox-desktop --dev-key $DEV_KEY &
          DESKTOP_PID=$!
          bash tests/e2e-desktop/scripts/run-all.sh
          TEST_EXIT=$?
          kill $DESKTOP_PID 2>/dev/null || true
          diskutil unmount force ~/CipherBox 2>/dev/null || true
          exit $TEST_EXIT
      ```

    - Windows:
      ```yaml
      - name: Run desktop E2E tests (Windows)
        if: runner.os == 'Windows'
        shell: powershell
        run: |
          $env:CIPHERBOX_API_URL = "http://localhost:3000"
          $env:VITE_API_URL = "http://localhost:3000"
          $env:VITE_TEST_LOGIN_SECRET = "e2e-test-secret-ci-only"
          $env:RUST_LOG = "info"
          $DEV_KEY = -join ((1..32) | ForEach-Object { '{0:x2}' -f (Get-Random -Max 256) })
          $proc = Start-Process -FilePath ".\desktop-binary\cipherbox-desktop.exe" -ArgumentList "--dev-key",$DEV_KEY -PassThru -NoNewWindow
          & "$PWD\tests\e2e-desktop\scripts\run-all.ps1"
          $testExit = $LASTEXITCODE
          Stop-Process -Id $proc.Id -Force -ErrorAction SilentlyContinue
          exit $testExit
      ```

14. **Upload logs on failure:**
    ```yaml
    - name: Upload logs on failure
      if: failure()
      uses: actions/upload-artifact@v4
      with:
        name: e2e-desktop-logs-${{ matrix.platform }}
        path: |
          apps/api/*.log
          ~/Library/Logs/fuse-t/fuse-t.log
        retention-days: 7
    ```

**Critical implementation details:**

- The `IDENTITY_JWT_PRIVATE_KEY` secret is required for the API's identity JWT issuing. Reference it from repository secrets.
- For the Windows API start step, use PowerShell to start node as a background job: `Start-Process -FilePath node -ArgumentList "dist/main.js" -NoNewWindow` in the apps/api directory.
- Environment variables for the API startup step must include all DB/IPFS/Redis vars (same as in e2e.yml).
- The desktop binary .env is loaded by dotenvy from the parent of src-tauri. Since we're running the binary from `desktop-binary/`, create the .env at `apps/desktop/.env` AND set env vars explicitly. The binary reads CIPHERBOX_API_URL > VITE_API_URL from environment.
- Linux needs Xvfb for the Tauri webview (WebKitGTK). Use `GabrielBB/xvfb-action@v1` to wrap the test execution.
- macOS does NOT need Xvfb (display available on macOS runners).

**AVOID these anti-patterns:**

- Do NOT rebuild Rust from source -- download the artifact
- Do NOT use Docker `services:` block -- only works on Linux
- Do NOT use release binary -- `--dev-key` is debug-only
- Do NOT hardcode mount paths -- use `$HOME/CipherBox` / `$env:USERPROFILE\CipherBox`
- Do NOT skip Redis -- API BullMQ requires it
