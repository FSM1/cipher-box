## Decisions Made

- **Invoke-RestMethod over Invoke-WebRequest:** PowerShell round-trip scripts use `Invoke-RestMethod` which auto-parses JSON responses, eliminating the need for manual `ConvertFrom-Json` calls. The plan's task description explicitly specified this cmdlet.
- **Exit code = failure count:** Test scripts exit with the number of failed tests rather than simple 0/1, allowing the orchestrator to aggregate total failures across all test suites.
- **Cross-platform SHA-256 detection:** FUSE operations script auto-detects `shasum -a 256` (macOS) vs `sha256sum` (Linux) at startup to handle binary file verification.
