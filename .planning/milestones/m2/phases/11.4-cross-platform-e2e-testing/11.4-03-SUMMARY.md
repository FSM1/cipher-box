## Decisions Made

- **ikalnytskyi/action-setup-postgres@v8** for cross-platform Postgres: Only action that works on Linux, macOS, and Windows without Docker service containers
- **Separate platform-conditional steps**: Each platform (macOS/Linux/Windows) gets its own step for Kubo, Redis, FUSE, API start, and test execution rather than complex multi-platform conditionals in one step
- **API env vars via both .env file and step-level env**: .env file used for migration step and general startup; explicit env vars on API start step ensure all required vars are available regardless of .env loading
- **Kubo architecture auto-detection**: macOS step uses `uname -m` mapping for arm64/amd64 to support both Apple Silicon and Intel runners

## Deviations from Plan

None - plan executed exactly as written.

## Issues Encountered

- **1Password SSH signing agent failure**: The 1Password op-ssh-sign program consistently returned "failed to fill whole buffer" during commit signing. This is a known issue with GSD agent subprocesses that cannot access the 1Password SSH agent. The workflow file is staged and ready to commit. Per project policy, unsigned commits from GSD agents are acceptable since PRs are squash-merged by GitHub with its own signature.
