## Milestone Summary

**Decimal Phases (10 inserted):**

- Phase 11.1: macOS Desktop Catch-Up (catch up desktop to web features from 12-12.6)
- Phase 11.2: Remove v1 Folder Metadata (eliminate dual-schema)
- Phase 11.3: Linux Desktop (third platform)
- Phase 11.4: Cross-Platform E2E Testing (CI validation matrix)
- Phase 12.1: AES-CTR Streaming Encryption (media playback)
- Phase 12.2: Encrypted Device Registry (cross-device infrastructure)
- Phase 12.3: SIWE + Unified Identity (wallet login)
- Phase 12.3.1: Pre-Wipe Identity Cleanup (deterministic IPNS, hashed identifiers)
- Phase 12.5: MFA Polishing, UAT & E2E Testing (quality gate)
- Phase 17.1: Recycle Bin Integration Fixes (audit gap closure)

**Key Decisions:**

- Core Kit MPC replaces PnP Modal SDK (self-hosted identity provider)
- Per-file IPNS metadata split (decouple content from folder publishes)
- AES-256-CTR for streaming media (GCM for all other files)
- SIWE wallet login with SHA-256 hashed identifiers (privacy-preserving)
- Optimistic concurrency via IPNS sequence numbers (not distributed locks)
- Encrypted recycle bin on IPFS (client-side retention enforcement)
- FUSE-T SMB backend (replaced NFS due to macOS kernel bug)

**Issues Resolved:**

- FUSE-T NFS kernel bug — switched to SMB backend
- PnP-to-Core-Kit migration — importTssKey preserves user keys
- v1/v2 dual-schema — eliminated, v2 FilePointer canonical
- Bin CID unpinning — contentCid captured at soft-delete time
- Windows bin bypass — spawn_bin_entry_publish added to WinFsp

**Tech Debt (9 LOW items):**

1. useDeviceRegistrySync hook orphaned (Phase 12.2)
2. Desktop Rust vault init uses random keygen not HKDF (Phase 12.3.1)
3. Settings.tsx doesn't parse ?tab=security URL param (Phase 12.4)
4. OCC covers folder metadata but not per-file IPNS publishes (Phase 16)
5. addManyFiles/removeMany not atomic with metadata publish (Phase 16)
6. No telemetry/metrics for conflict frequency (Phase 16)
7. Lazy rotation metadata conflict defers to next sync (Phase 16)
8. get_public_key() in ed25519.rs unzeroized stack copy (Phase 11.1)
9. Missing desktop E2E for conflict detection in all CI workflows (Phase 16)

**Deferred to M3:**

- SYNC-05: Offline write queue with retry
- SYNC-06: Idempotency keys for queued ops
- TEE-06: AWS Nitro fallback TEE provider (Phase 22)
