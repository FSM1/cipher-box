<objective>
Remove dead migration infrastructure from the API: drop the DB columns that stored crypto material (now living exclusively in IPFS v2 blobs), remove the POST /vault/migrate endpoint and migrateVault service method, simplify entity/DTOs/service to reflect that the server stores zero crypto material, and regenerate the API client.

Purpose: Eliminate dead code paths, reduce security surface area, and simplify the vault schema now that all users are on v2 blobs and no non-migrated vaults exist in any environment.

Output: Simplified vault API with no crypto columns, no migration endpoint, regenerated API client.
</objective>
