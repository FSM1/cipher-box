<objective>
Add a zizmor CI hard gate (CLI plain mode) that fails on `unpinned-uses` and `excessive-permissions`, and fix the existing `excessive-permissions` finding by adding least-privilege `permissions:` blocks to every job/workflow currently running with the inherited default write token (per D-04).

Purpose: Lock in the SHA-pinning from 53-01 against regression (any future `uses: action@vX` fails the build — T-53-01) and remove excessive CI token privilege so a compromised action cannot escalate via a write-capable `GITHUB_TOKEN` (T-53-02). This plan depends on 53-01 because zizmor's `unpinned-uses` audit only passes once all refs are SHA-pinned.

Output: new `.github/workflows/zizmor.yml` gate; least-privilege permissions on all 11 unscoped ci.yml jobs and the 4 no-permissions-block workflows (desktop-e2e, web-e2e, load-test, release-gate) plus the partial workflows (ci-e2e, tag-staging) where jobs still lack blocks.
</objective>

<threat_model>

## Trust Boundaries

| Boundary | Description |
| --- | --- |
| third-party action → CI runner GITHUB_TOKEN | A compromised action can use an over-broad token to write to the repo, create releases, or comment on PRs |
| future PR author → workflow files | A new unpinned `uses:` ref could reintroduce the mutable-tag risk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-53-01 | Tampering | new/regressed `uses:` refs | mitigate | zizmor CLI gate (`unpinned-uses`) fails the build on any non-SHA-pinned ref — locks in 53-01 against regression (D-04) |
| T-53-02 | Elevation of Privilege | CI job GITHUB_TOKEN scope | mitigate | least-privilege job-level `permissions:` (`contents: read` default) + workflow-level `permissions: {}` deny-all so no job runs with default write token; zizmor `excessive-permissions` enforces it (D-04) |
| T-53-SC | Tampering | zizmor tool install | accept | `pip install zizmor` runs in an ephemeral CI runner, not added to any project manifest — no Package Legitimacy gate required (53-RESEARCH.md: no packages added) |

</threat_model>
