<objective>
SHA-pin all ~111 third-party GitHub Action `uses:` refs across the 14 workflow files to immutable 40-char commit SHAs with trailing `# vX.Y.Z` version comments, using `pinact run` (bulk, all-at-once, one PR per D-01/D-02). Verify the pre-existing `.github/dependabot.yml` `github-actions` ecosystem block covers the pinned SHAs (D-03 — NO new block).

Purpose: Eliminate the mutable-tag supply-chain attack surface (tag-hijacking of `@v6`/`@v0` refs — T-53-01). Mutable tags can be repointed by a compromised action author to malicious code; immutable SHAs cannot. This is the foundational plan — the zizmor gate (53-02) and all permissions work depend on the pins already being in place.

Output: All 14 workflow files with every third-party `uses:` ref SHA-pinned + version-commented; `.github/dependabot.yml` confirmed (unchanged) to keep the pins current.
</objective>
