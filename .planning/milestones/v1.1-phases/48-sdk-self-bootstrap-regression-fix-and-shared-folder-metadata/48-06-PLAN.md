| -------- | ----------- |
| browser → API | itemName must be ECIES-wrapped before leaving the browser; only ciphertext is sent for new/updated rows |
| stored ciphertext → display | Decryption happens client-side with the vault private key; plaintext exists only in the browser projection |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --------- | -------- | --------- | ----------- | --------------- |
| T-48-15 | Information Disclosure | itemName in transit / at rest | mitigate | ECIES wrapKey with recipient pubkey before createShare; only ciphertext sent; server stores bytea only (Task 2) — closes M1 |
| T-48-16 | Information Disclosure | legacy plaintext rows | mitigate | Lazy client backfill re-wraps + re-persists ciphertext on next owner load, idempotent; closes M1 over time without a server-side encrypt (decision A2, Task 2) |
| T-48-17 | Information Disclosure | vault private key / unwrapped name in memory | mitigate | Decrypt happens transiently for display; clear transient unwrapped key bytes after use (CLAUDE.md rule 9); never log itemName/itemNameEncrypted (Task 2) |
| T-48-18 | Tampering | display fallback | accept | Legacy rows without ciphertext fall back to plaintext itemName for display continuity until backfilled — acceptable transitional state (decision A2) |
