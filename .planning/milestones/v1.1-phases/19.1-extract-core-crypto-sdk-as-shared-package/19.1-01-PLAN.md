<objective>
Split the existing `@cipherbox/crypto` package into `@cipherbox/crypto` (pure primitives + key derivation) and a new `@cipherbox/core` package (CipherBox domain types, metadata schemas, validators, metadata encrypt/decrypt, vault init, IPNS record creation).

Purpose: Establish the foundation layer of the five-package SDK architecture. The core package contains everything that "knows about CipherBox's data model" while crypto retains only generic cryptographic operations. Transitional re-exports from crypto prevent breaking the 47 existing import sites in the web app.

Output: Two clean packages with correct dependency direction (core depends on crypto), all existing tests passing, monorepo building successfully.
</objective>
