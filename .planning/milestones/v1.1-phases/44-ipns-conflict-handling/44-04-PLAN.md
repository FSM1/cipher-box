<objective>
Sweep the SDK-package callers (D-08) so the three-way merge actually runs in production instead of always degrading to the union fallback. Every `updateFolderMetadataAndPublish` call in `packages/sdk` (8 in client.ts, 2 in bin/index.ts, 4 in shared-write.ts) is updated to pass a `baseChildren` snapshot taken BEFORE the local mutation. The headline case — `shared-write.ts` write-shares — moves off union fallback to true three-way merge. The one `updateFileMetadata` call in shared-write.ts is rewired to the new Plan 03 return shape (now publishes internally with CAS).

Purpose: Plans 02/03 make the merge available but backward-compatible; the unswept callers all hit the union fallback (which resurrects deletes and logs a warning). This plan closes the gap for the SDK package so concurrent writers — especially write-share recipients — converge correctly with deletes honored.
Output: 14 call sites in 3 files updated; ConflictError left to propagate; no new prunedCids leak introduced.
</objective>
