<objective>
Convert the TypeScript resolve path (`packages/sdk-core/src/ipns/index.ts` `resolveIpnsRecord`) to a strict fail-closed model: delete the legacy `else` fall-through so a record lacking signature fields throws (D-05), drop the first-publish skew disjunct to strict sequence equality (D-05), and add resolve-side EOL/expiry enforcement by parsing the CBOR `Validity` field (D-07 TS path).

Purpose: This is the TS twin of Plan 01's Rust strict verifier. It has no file overlap with the Rust crates, so it runs in Wave 1 in parallel. Plan 05's API codec/service tightening and Plan 06's caching depend on this strict client contract being defined.
Output: `resolveIpnsRecord` throws on missing-signature, skew, and expiry; new throw-path unit tests.
</objective>
