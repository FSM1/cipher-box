<objective>
Relocate the verified-IPNS-resolve chokepoint from `crates/fuse/src/verify.rs` into `crates/api-client/src/ipns.rs` so all Rust consumers (sdk, fuse, desktop) share one implementation (D-08), and harden it to a strict fail-closed model: remove the `Legacy` degraded-acceptance branch and the first-publish skew allowance (D-04), and add resolve-side EOL/expiry enforcement (D-07 Rust path).

Purpose: This is the Rust foundation of the cross-layer strict cutover. Every Wave-2 Rust routing change (D-04 caller folding, D-08 sdk bypass closure, D-09 desktop routing) imports the relocated wrapper, so it MUST land first.
Output: A single `resolve_ipns_verified` entrypoint in `cipherbox-api-client` that fails closed on tampered CID, missing/invalid signature, sequence skew, and expiry.
</objective>

## Trust Boundaries

| Boundary | Description |
| -------- | ----------- |
| API/DHT → Rust client | Resolved IPNS response (cid, seq, signatureV2, data, pubKey) crosses from an untrusted source into the verified resolver |
| crate boundary (fuse/sdk/desktop → api-client) | Consumers depend on the single chokepoint; a weakened chokepoint weakens every consumer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --------- | -------- | --------- | ----------- | --------------- |
| T-60-01 | Tampering | bind_verified CID binding | mitigate | Strict `embedded_value == /ipfs/{resp.cid}` (kept); CID-swap test asserts Invalid |
| T-60-02 | Spoofing | verify_ipns_resolve_signature absent-fields path | mitigate | Remove Ok(None) legacy branch → absent fields produce Some(false) → Invalid (D-04) |
| T-60-03 | Tampering | bind_verified sequence binding | mitigate | Strict `embedded_seq == resp_seq` (skew disjunct removed); skew test asserts Invalid (D-04) |
| T-60-04 | Tampering | expired-record replay on resolve | mitigate | EOL/expiry check in bind_verified with 5-min skew buffer; missing Validity is fail-closed (D-07) |
| T-60-05 | Elevation | wrapper relocation weakening the chokepoint (D-08) | mitigate | fuse re-export preserves call surface; relocated unit tests are the regression net; no behavior softened during move |

</threat_model>
