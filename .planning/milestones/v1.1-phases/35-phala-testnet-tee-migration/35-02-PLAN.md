<task type="auto">
  <name>Task 3: Unit tests for epoch fallback orchestration (key-manager.ts)</name>
  <files>apps/tee-worker/src/__tests__/key-manager.test.ts</files>

    - apps/tee-worker/src/services/key-manager.ts (decryptWithFallback, reEncryptForEpoch -- now using @cipherbox/crypto)
  </read_first>
  <action>
Test the TEE-specific epoch fallback orchestration. The underlying ECIES encrypt/decrypt is already tested in @cipherbox/crypto -- here we test the fallback logic:

1. **decryptIpnsKey:** Encrypt a test key with epoch N public key, decrypt with epoch N succeeds
2. **decryptWithFallback - current epoch wins:** Key encrypted with current epoch decrypts on first try
3. **decryptWithFallback - previous epoch fallback:** Key encrypted with previous epoch falls back and succeeds
4. **decryptWithFallback - both fail:** Returns descriptive error when neither epoch works
5. **decryptWithFallback - no previous epoch:** null previousEpoch skips fallback, fails immediately
6. **reEncryptForEpoch:** Decrypt with old epoch, re-encrypt for new epoch, verify new-epoch decrypt works
7. **Private key zeroing:** After decryptIpnsKey, the TEE keypair private key buffer is zeroed

Use real HKDF-derived keys (simulator mode) and real @cipherbox/crypto wrapKey to create test ciphertexts. No mocking needed.
</action>
