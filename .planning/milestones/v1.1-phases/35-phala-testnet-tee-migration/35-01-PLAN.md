<objective>
Move the TEE worker from the repo root into apps/tee-worker/ (consistent with apps/api and apps/web), then refactor it to consume shared monorepo packages (@cipherbox/crypto, @cipherbox/core, @cipherbox/sdk-core) instead of reimplementing IPNS signing, ECIES encryption, and provider interactions from scratch.

Purpose: The TEE worker currently sits outside the standard apps/ convention and vendors its own copies of eciesjs, @noble/ed25519, ipns, @libp2p/crypto, and multiformats -- duplicating ~400 lines of logic that already exists in tested shared packages. This creates maintenance burden, security risk, and silent divergence. Moving to apps/ and consuming shared packages fixes both structural and architectural issues in one pass.

Output: TEE worker at apps/tee-worker/, consuming shared packages, reduced direct dependencies, KuboProvider/PsaProvider enhanced with fetch injection for TEE SSRF safety
</objective>

```typescript
/**
 * IPNS Record Signing Service
 *
 * Delegates to @cipherbox/core for IPNS record creation and marshaling.
 * TEE-specific: Uses 48-hour record lifetime (vs 24h default) to provide
 * comfortable margin with 6-hour republish interval.
 */

import { createIpnsRecord, marshalIpnsRecord } from '@cipherbox/core';

/** 48-hour IPNS record lifetime for TEE-republished records */
const TEE_RECORD_LIFETIME_MS = 48 * 60 * 60 * 1000;

/**
 * Sign an IPNS record with an Ed25519 private key.
 */
export async function signIpnsRecord(
  ed25519PrivateKey: Uint8Array,
  cid: string,
  sequenceNumber: bigint
): Promise<Uint8Array> {
  const record = await createIpnsRecord(
    ed25519PrivateKey,
    '/ipfs/' + cid,
    sequenceNumber,
    TEE_RECORD_LIFETIME_MS
  );
  return marshalIpnsRecord(record);
}
```

Caller interface unchanged -- no changes needed in republish.ts.
