**Create `apps/web/src/components/file-browser/UploadListItem.tsx`:**

Create a new component that renders an inline upload row matching the `FileListItem` grid layout. The component subscribes to the upload store with fine-grained selectors to avoid re-rendering the entire FileList on every progress update.

```typescript
import { useEffect, useRef, useCallback } from 'react';
import { useUploadStore } from '../../stores/upload.store';
import type { PerFileUpload } from '../../stores/upload.store';
```

**Props:** `{ fileId: string; onRetry?: (file: File) => void }`

**Store subscription -- use fine-grained selector:**

```typescript
const file = useUploadStore((s) => s.files.get(fileId));
const cancelFile = useUploadStore((s) => s.cancelFile);
const removeFile = useUploadStore((s) => s.removeFile);
const retryFile = useUploadStore((s) => s.retryFile);
```

**Early return:** If `!file` return `null`.

**Status-derived values:**

- `isError = file.status === 'error'`
- `isComplete = file.status === 'complete'`
- `isEncrypting = file.status === 'encrypting'`

**Completion flash timer (D-05, D-06):**
Use `useRef<ReturnType<typeof setTimeout>>` for the completion timer. In a `useEffect` watching `file.status`:

- When status becomes `'complete'`, start a 1000ms timer that calls `removeFile(fileId)`.
- Clear the timer on cleanup (unmount or status change) to prevent memory leaks (Pitfall 4).
- Do NOT delay the next file's upload -- this is UI-only timing.

**Cancel handler (D-07, D-08):**

```typescript
const handleCancel = useCallback(() => {
  cancelFile(fileId);
  removeFile(fileId); // Immediate removal per D-08
}, [fileId, cancelFile, removeFile]);
```

**Dismiss handler (D-10):**

```typescript
const handleDismiss = useCallback(() => {
  removeFile(fileId);
}, [fileId, removeFile]);
```

**Retry handler (D-09):**

The retry handler calls `retryFile(fileId)` to reset the store entry's visual state, then calls `onRetry(file.file)` to re-trigger the actual upload. Without `onRetry`, clicking retry would only reset the progress bar but never re-upload the file.

```typescript
const handleRetry = useCallback(() => {
  retryFile(fileId);
  if (file?.file && onRetry) {
    onRetry(file.file);
  }
}, [fileId, retryFile, file?.file, onRetry]);
```
