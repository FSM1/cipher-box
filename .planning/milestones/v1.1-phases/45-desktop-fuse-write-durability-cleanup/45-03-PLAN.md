<objective>
Replace the empty-string `file_meta_ipns_name` sentinel in `JournalOp::UploadFile` with `Option<String>` (#18), and add a serde-compat deserializer so journals written by the old build (which stored `""`) still replay. This is a crash-recovery-correctness change: dropping the compat shim would silently fail to load pre-Phase-45 journal entries on disk.

Purpose: The `""` sentinel is stringly-typed and forces every consumer to remember "empty means absent." `Option<String>` makes absence explicit. But because `JournalEntry` is JSON on disk, the type change alters the wire format (`""` → `null`/absent), so a deserialize compat shim is mandatory.
Output: `file_meta_ipns_name: Option<String>` with `#[serde(default, deserialize_with = "deser_opt_string")]`; write paths pass the Option directly; `replay_upload_entry` takes `Option<&str>`; T-45-04 (None round-trip) + T-45-04-compat (old `""` loads as None) tests.
</objective>
