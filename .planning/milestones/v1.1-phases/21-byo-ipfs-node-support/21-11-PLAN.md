<task type="checkpoint:human-action" gate="blocking">
  <name>Task 1: Configure external IPFS provider for benchmarking</name>
  <files>N/A -- human configuration step</files>
  <action>
    BYO load test scenarios (from Plan 21-07) and PinataProvider (from Plan 21-10) are ready to run.
    The human must configure an external IPFS provider before benchmarks can execute.

    Set up ONE of these options:

    **Option A: Pinata (recommended -- free tier available)**
    1. Create account at https://www.pinata.cloud/
    2. Go to API Keys -> New Key -> create a JWT with pinning permissions
    3. Set environment variables:
       export BYO_IPFS_ENDPOINT=https://api.pinata.cloud
       export BYO_IPFS_AUTH_TOKEN=[your-pinata-jwt]
       export BYO_IPFS_PROTOCOL=pinata
       export BYO_IPFS_PROVIDER_NAME=Pinata

    **Option B: Self-hosted Kubo node with external access**
    1. Ensure Kubo RPC is accessible from the test runner
    2. Set environment variables:
       export BYO_IPFS_ENDPOINT=https://your-kubo-node:5001
       export BYO_IPFS_AUTH_TOKEN=[basic-auth-token]
       export BYO_IPFS_PROTOCOL=kubo
       export BYO_IPFS_PROVIDER_NAME="Self-hosted Kubo"

    **Option C: Filebase (S3-compatible IPFS pinning)**
    1. Create account at https://filebase.com/
    2. Set environment variables with PSA endpoint

    Verify the provider is accessible:
    For Pinata: curl -H "Authorization: Bearer $BYO_IPFS_AUTH_TOKEN" https://api.pinata.cloud/data/testAuthentication
    For Kubo: curl -X POST -H "Authorization: Basic $BYO_IPFS_AUTH_TOKEN" $BYO_IPFS_ENDPOINT/api/v0/id

  </action>
  <verify>echo "Provider: $BYO_IPFS_PROVIDER_NAME" and echo "Protocol: $BYO_IPFS_PROTOCOL" -- both should return non-empty values</verify>
  <done>External IPFS provider configured with BYO_IPFS_ENDPOINT, BYO_IPFS_AUTH_TOKEN, BYO_IPFS_PROTOCOL, and BYO_IPFS_PROVIDER_NAME environment variables set. Human confirms "provider ready" or "skip baselines".</done>
