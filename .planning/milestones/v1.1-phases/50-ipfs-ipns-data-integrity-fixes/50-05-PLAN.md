| Boundary                              | Description                                                                                |
| ------------------------------------- | ------------------------------------------------------------------------------------------ |
| authenticated client → unpin endpoint | `UnpinDto.cid` is untrusted input crossing into DB queries and Kubo calls                  |
| failed-upload compensation → Kubo     | A `recordPin` failure must not leave an orphan pin paid for by hosted storage              |
| offline backfill script → pinned_cids | A maintenance script deleting "phantom" rows must not race active uploads                  |
