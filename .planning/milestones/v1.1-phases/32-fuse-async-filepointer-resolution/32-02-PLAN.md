# Plan 32-02: Refactor drain_refresh_completions to Spawn Async FilePointer Resolution

<objective>
Replace the synchronous `block_with_timeout()` loop inside `drain_refresh_completions()` (lines 617-643 of lib.rs) with async task spawning via the new `filepointer_tx` channel. Each unresolved FilePointer gets a tokio task that resolves IPNS, fetches content, decrypts metadata, and sends the result through the channel. The dedup guard `resolving_file_pointers` prevents duplicate spawns. Also add `drain_filepointer_completions()` calls at the start of `handle_readdir()` so resolved results are applied on the next FUSE callback.
</objective>

<must_haves>

- The `block_with_timeout()` call for FilePointers inside `drain_refresh_completions()` is completely removed
- Unresolved FilePointers spawn tokio async tasks instead of blocking
- Each spawned task uses `filepointer_tx` to send `PendingFilePointer::Success` or `PendingFilePointer::Failure`
- The `resolving_file_pointers` HashSet is checked before spawning (skip if already in-flight)
- The inode number is inserted into `resolving_file_pointers` before spawning the task
- `drain_filepointer_completions()` is called at the start of `handle_readdir()` (alongside existing `drain_refresh_completions()`)
- Retry logic: on failure, ino is removed from dedup set so the next folder refresh cycle re-attempts resolution (organic retry via metadata cache TTL + readdir refresh, no explicit retry counter needed -- the 30s polling cadence provides natural exponential backoff equivalent)
- FilePointer resolution timeout uses `NETWORK_TIMEOUT` (10s) per task, not `CONTENT_DOWNLOAD_TIMEOUT` (120s)
</must_haves>

```rust
            // Spawn async resolution for unresolved FilePointers in this folder
            let unresolved = self.inodes.get_unresolved_file_pointers_for_parent(refresh.ino);
            if !unresolved.is_empty() {
                let folder_key = self.inodes.get(refresh.ino).and_then(|i| match &i.kind {
                    inode::InodeKind::Root { .. } => Some(self.root_folder_key.to_vec()),
                    inode::InodeKind::Folder { folder_key, .. } => Some(folder_key.to_vec()),
                    _ => None,
                });
                if let Some(fk) = folder_key {
                    for (ino, fp_ipns) in unresolved {
                        if self.resolving_file_pointers.contains(&ino) {
                            continue; // Already in-flight
                        }
                        if let Ok(fk_arr) = <[u8; 32]>::try_from(fk.as_slice()) {
                            self.resolving_file_pointers.insert(ino);
                            let api = self.api.clone();
                            let tx = self.filepointer_tx.clone();
                            self.rt.spawn(async move {
                                let result = tokio::time::timeout(
                                    NETWORK_TIMEOUT,
                                    async {
                                        let resp = cipherbox_api_client::ipns::resolve_ipns(&api, &fp_ipns)
                                            .await.map_err(|e| format!("{}", e))?;
                                        let enc_bytes = cipherbox_api_client::ipfs::fetch_content(&api, &resp.cid)
                                            .await.map_err(|e| format!("{}", e))?;
                                        cipherbox_core::decrypt_file_metadata_from_ipfs_public(&enc_bytes, &fk_arr)
                                    },
                                ).await;

                                match result {
                                    Ok(Ok(fm)) => {
                                        log::debug!("FilePointer async resolved for ino {} (cid={})", ino, &fm.cid[..fm.cid.len().min(12)]);
                                        let _ = tx.send(PendingFilePointer::Success {
                                            ino,
                                            cid: fm.cid,
                                            encrypted_file_key: fm.file_key_encrypted,
                                            iv: fm.file_iv,
                                            size: fm.size,
                                            encryption_mode: fm.encryption_mode,
                                            versions: fm.versions,
                                        });
                                    }
                                    Ok(Err(e)) => {
                                        log::warn!("FilePointer resolve failed for ino {}: {}", ino, e);
                                        let _ = tx.send(PendingFilePointer::Failure { ino });
                                    }
                                    Err(_) => {
                                        log::warn!("FilePointer resolve timed out for ino {} ({}s)", ino, NETWORK_TIMEOUT.as_secs());
                                        let _ = tx.send(PendingFilePointer::Failure { ino });
                                    }
                                }
                            });
                        }
                    }
                }
            }
```

Key changes from the old code:
- Uses `get_unresolved_file_pointers_for_parent(refresh.ino)` instead of `get_unresolved_file_pointers()` to scope resolution to the refreshed folder (avoids resolving FilePointers with the wrong folder key)
- Checks `self.resolving_file_pointers.contains(&ino)` before spawning (dedup guard)
- Inserts `ino` into `self.resolving_file_pointers` before spawning
- Spawns a tokio task with `self.rt.spawn()` instead of calling `block_with_timeout()`
- Task sends `PendingFilePointer::Success` or `PendingFilePointer::Failure` via `self.filepointer_tx`
- Uses `NETWORK_TIMEOUT` (10s) timeout per resolution, not CONTENT_DOWNLOAD_TIMEOUT
</action>
