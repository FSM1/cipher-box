# Plan 32-01: Add PendingFilePointer Channel Infrastructure to CipherBoxFS

<objective>
Add the `PendingFilePointer` enum, a new `std::sync::mpsc` channel pair (`filepointer_tx`/`filepointer_rx`), a `resolving_file_pointers: HashSet<u64>` dedup guard, and a `drain_filepointer_completions()` method to `CipherBoxFS`. This mirrors the existing `PendingContent` + `content_tx`/`content_rx` + `prefetching` pattern for content prefetch, but for FilePointer IPNS resolution results.
</objective>

<must_haves>

- A `PendingFilePointer` enum with `Success` and `Failure` variants carrying resolution data
- A `filepointer_tx: std::sync::mpsc::Sender<PendingFilePointer>` field on `CipherBoxFS`
- A `filepointer_rx: std::sync::mpsc::Receiver<PendingFilePointer>` field on `CipherBoxFS`
- A `resolving_file_pointers: std::collections::HashSet<u64>` dedup guard field on `CipherBoxFS`
- A `drain_filepointer_completions()` method that drains the channel and applies resolved metadata to inodes
- Channel pair initialized in the same location where `content_tx`/`content_rx` are initialized
</must_haves>

### Task 2: Add drain_filepointer_completions() method

<read_first>

- crates/fuse/src/lib.rs lines 648-655 (drain_content_prefetches pattern to mirror)
- crates/fuse/src/inode.rs lines 621-657 (resolve_file_pointer method signature and behavior)
</read_first>

<action>
Add a `drain_filepointer_completions()` method to the `impl CipherBoxFS` block in `crates/fuse/src/lib.rs`, right after the existing `drain_content_prefetches()` method (after line 655):

```rust
    /// Drain completed FilePointer async resolution results.
    /// Mirrors drain_content_prefetches() — applies resolved metadata to inodes
    /// and removes entries from the resolving_file_pointers dedup guard.
    pub fn drain_filepointer_completions(&mut self) {
        while let Ok(msg) = self.filepointer_rx.try_recv() {
            match msg {
                PendingFilePointer::Success {
                    ino,
                    cid,
                    encrypted_file_key,
                    iv,
                    size,
                    encryption_mode,
                    versions,
                } => {
                    self.resolving_file_pointers.remove(&ino);
                    self.inodes.resolve_file_pointer(
                        ino,
                        cid,
                        encrypted_file_key,
                        iv,
                        size,
                        encryption_mode,
                        versions,
                    );
                    log::debug!("FilePointer resolved async for ino {}", ino);
                }
                PendingFilePointer::Failure { ino } => {
                    self.resolving_file_pointers.remove(&ino);
                    log::warn!("FilePointer async resolution failed for ino {}", ino);
                }
            }
        }
    }
```
</action>

<acceptance_criteria>

- `crates/fuse/src/lib.rs` contains `pub fn drain_filepointer_completions(&mut self)`
- Method calls `self.filepointer_rx.try_recv()` in a while-let loop
- On `PendingFilePointer::Success`: calls `self.resolving_file_pointers.remove(&ino)` and `self.inodes.resolve_file_pointer(ino, cid, encrypted_file_key, iv, size, encryption_mode, versions)`
- On `PendingFilePointer::Failure`: calls `self.resolving_file_pointers.remove(&ino)`
- `cargo check --features fuse -p cipherbox-fuse` succeeds
</acceptance_criteria>
