## Decisions Made

- **Promise.allSettled over Promise.all**: Promise.all would reject on first failure, losing the other operation's result. Promise.allSettled lets us check both results and handle each independently.
- **Folder metadata failure is critical**: The FilePointer in folder metadata is the source of truth for file discovery. Without it, the uploaded file would be orphaned.
- **IPNS batch publish failure is non-critical**: The file's IPNS record is supplementary -- the FilePointer in folder metadata already references the file. The IPNS record will be created on next publish attempt or TEE republish cycle.
- **Baselines from existing Phase 19 data**: Local API was not running; used existing load test metrics from the same date as the pre-optimization reference with a documented caveat.
