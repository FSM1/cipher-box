<objective>
Move Windows WinFsp operation files from the desktop app to the cipherbox-fuse crate, closing the last verification gap from Phase 23.

Purpose: The cipherbox-fuse crate declares `#[cfg(feature = "winfsp")] pub mod windows` in platform/mod.rs but the directory does not exist, causing a latent compile error. The 4 operation files (operations.rs, read_ops.rs, write_ops.rs, dir_ops.rs) contain platform-specific FUSE logic that belongs in the crate, not the desktop app. The mount/unmount function (mod.rs) uses AppState and stays in the desktop.

Output: Windows WinFsp operations live in `crates/fuse/src/platform/windows/`, desktop `fuse/windows/` is reduced to mount/unmount only, `block_with_timeout` made public for cross-module use.
</objective>
