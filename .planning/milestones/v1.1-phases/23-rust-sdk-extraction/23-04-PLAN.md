<objective>
Extract the `cipherbox-fuse` crate containing all FUSE filesystem abstractions and platform-specific implementations. Platform-agnostic data structures (InodeTable, MetadataCache, ContentCache, FileHandle) are shared. Platform-specific mount/unmount and callback implementations are behind feature flags.

Purpose: Separates filesystem logic from the Tauri application shell, enabling unit testing of FUSE data structures independently and clean platform module boundaries.

Output: `crates/fuse/` crate with shared + platform modules, desktop app rewired to depend on the crate.
</objective>

```rust
//! CipherBox FUSE filesystem implementation.

//! Platform-agnostic data structures (InodeTable, MetadataCache, ContentCache,

pub mod platform;

// Re-exports
pub use inode::{InodeTable, InodeData};
pub use cache::{MetadataCache, ContentCache};
pub use file_handle::FileHandle;
pub use error::FuseError;
```
