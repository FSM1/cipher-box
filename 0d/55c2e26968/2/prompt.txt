2. Key Technical Concepts:
   - **Web3Auth MPC Core Kit**: The authentication SDK used by CipherBox. Uses Threshold Secret Sharing (TSS) to split keys into factors.
   - **hashedShare**: A cloud custodial key automatically created by MPC Core Kit during account setup. Has `module: "hashedShare"` and `tssShareIndex: 2`. It is **deleted** when `enableMFA()` is called.
   - **Default account state**: Every fresh account has `totalFactors: 2` (JWT verifier share + hashedShare), `threshold: 2`. This is the baseline semi-custodial state.
   - **enableMFA() behavior**: Deletes the hashedShare, creates a device factor + recovery factor, pushing `totalFactors` to 3+. Transitions account from semi-custodial to fully non-custodial.
   - **CipherBox JWT custom provider**: Web3Auth is NOT using social login directly. CipherBox backend authenticates users and issues a JWT used with Web3Auth as a custom verifier. The user explicitly corrected this misunderstanding.
   - **Bug**: `details.totalFactors >= 2` is always true for every account, causing false positive MFA enabled status.
   - **Fix**: Change to `details.totalFactors > 2` — after enableMFA(), factors go to 3+.
   - **GSD Quick Task**: The project's task execution framework for small atomic changes with planning docs, STATE.md tracking, and atomic commits.
